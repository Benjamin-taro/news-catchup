## 1. Claude Code の Code Review が正式版に。Team・Enterprise の PR を 6〜10 分でレビュー、承認やブロックはしない
![](https://res.cloudinary.com/zenn/image/upload/s--_cqzt2kb--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:Claude%2520Code%2520%25E9%2580%25B1%25E9%2596%2593%25E3%2583%258B%25E3%2583%25A5%25E3%2583%25BC%25E3%2582%25B9%25EF%25BC%258810%252F11%25E3%2580%259C10%252F17%25EF%25BC%2589%25EF%25BC%259ACode%2520Review%2520%25E6%25AD%25A3%25E5%25BC%258F%25E7%2589%2588%25E3%2583%25BBidle%2520comp...%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:%25E3%2581%259A%25E3%2582%2593%25E3%2581%25A0%25E3%2582%2582%25E3%2582%2593%25E3%2581%25AE%25E5%25AE%259F%25E9%25A8%2593%25E9%2581%2593%25E5%2585%25B7%25E7%25AE%25B1%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyLzJiNGRhMmQyODEuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)
**一言で**：Claude Code の週間まとめ（Zenn）によると、10 月 15 日に GitHub PR の自動レビュー「Code Review」が Team・Enterprise 向けに正式版になり、同じ週に idle compaction など 2.1.299〜2.1.302 の挙動変更も入った。

- Code Review は管理者が有効にすれば開発者側の設定が不要。多くのレビューはプレビュー時の約 20 分から 6〜10 分になった。深さは Quick・Standard（既定）・Deep からリポジトリごとに選べる。PR の承認・ブロックはしない。
- 費用は利用者ではなく組織の usage credits に請求される。Enterprise は 2027 年 1 月 15 日までの申請で 1 万ドル以上のクレジットを受け取れる（受け取りから 30 日で失効）。Zero Data Retention・HIPAA 構成や CMEK の組織、Pro・Max は対象外（ローカルの `/code-review` は全プランで使える）。
- 2.1.299 の idle compaction は、20 万トークン超の会話を約 54 分放置すると 1 時間のキャッシュが切れる前に圧縮する（`"idleCompaction": false` で停止可）。MCP の allow ルール `mcp__a` は別サーバーに効かなくなり、PreToolUse の `updatedInput` は検証されて未知のキーは捨てられる。hooks で入力を書き換えている場合は確認が要る。

**So what**：レビューを「承認する人」ではなく「見落としを探す常時の検査」として製品化する動きで、10/17 の Anthropic 社内の事例の続きにあたる。時間短縮の数字は公式の説明で、第三者の検証は見当たらない。

## 2. 金融・EC で外部 AI エージェントの遮断が広がる。Citi・BofA・JPMorgan・Schwab は制限、Amazon は外部エージェント経由の購入を拒否
![](https://cdn.digitaltoday.co.kr/news/photo/202610/707940_655582_3259.jpg)
**一言で**：韓国の Digital Today（日本語版）が 10 月 18 日、WSJ の報道を引いて、銀行や EC が外部の AI エージェントによる取引を締め出し始めていると伝えた。

- 銀行では Citi、Bank of America、JPMorgan、Charles Schwab が外部 AI エージェントのアクセスを制限。理由は主にセキュリティで、エージェントが顧客の資金を高利回りの商品へ動かして預金が大量に流出する懸念もある。
- EC では、Yelp はデータ使用料を払うエージェントだけを許可し、Delta 航空は代理での航空券予約を遮断、Amazon は外部エージェント経由の買い物を禁止。一方 Target は承認した外部エージェントを受け入れ、Walmart は OpenAI・Google と提携、DoorDash は自前のエージェント「Ask」を出した。
- BrightEdge のデータでは、AI エージェント経由の購入は 4 月から約 4 倍、月 43% 増。ただし取引完了までエージェントに任せる提携 EC は 3% にとどまる。決済権限と顧客接点を失う懸念、返品やチャージバック、「誰の代理か」を確かめにくい点が理由に挙がる。

**So what**：エージェント決済の技術より前に、「エージェントを受け入れるかどうか」を各社が経営判断として分け始めている。銀行側の懸念は預金流出と本人確認で、権限管理の議論と同じ論点につながる。数字は BrightEdge の集計を WSJ 経由で引いた二次報道。

**一言で**：Zenn の記事が、CodeRabbit のレビュー依頼を約 70 分おきに出す仕組みをクラウドのセッションへ移そうとして、Claude Code に「お勧めしません」と返された経緯を書いた。

- 理由は 3 つ。Claude の GitHub アプリを 3 リポジトリに限定した過去の決定と、移したい 2 リポジトリが矛盾する。範囲を広げるとワークフローを変更できる権限まで渡り、絞った意味が薄れる。1 時間に 1 行コメントを書くだけの処理にクラウドの課金は見合わない。

- 著者は何も作らず、PC を開いている間だけ Claude が依頼する現状維持を選んだ。週末の趣味のプロジェクトなので遅れは許容でき、「レート制限を待つ」のも設計の一つだと結論している。

**So what**：記録した判断がエージェントの歯止めとして働いた個人の実例。実装の前に「やるべきか」を問い、最終判断を人に返す動きになっている。個人の体験談で、一般化できる数字はない。

## 4. 「検証可能性から組む」：人が全部読む前提をやめ、工程ごとに検査を置く。長時間エージェントは権限と時間を分けて設計する

## 5. Linux カーネルの深刻な脆弱性「PwnEscape」（CVE-2026-99999）。ゲスト VM からホスト OS でコードを実行できる可能性
![](https://www.publickey1.jp/2026/cve202699999.png)
**一言で**：Linux カーネルのネットワーク処理の欠陥で、悪意あるゲスト仮想マシンの利用者がホストの Linux OS で不正なコードを実行できる可能性があるとして、Publickey が 10 月 18 日に伝えた。

- 検証済みの IPv4 ヘッダーのチェックサム関連データを攻撃者が書き換えられ、想定外のメモリの読み書きにつながる。深刻度は 9.3（Critical）。技術詳細は 10 月 15 日に Openwall の oss-security に投稿され、現時点で脱出が確認されたのは研究環境のみ。
- さくらインターネットは 10 月 17 日時点で、さくらの VPS やレンタルサーバーなど一部サービスの新規申込みを停止して対策を開始。AWS はセキュリティ情報を出し、EC2・Lambda・Fargate など AWS 管理のサービスは「影響なし」とした。Amazon Linux 2 には修正の更新が出ている。
- 公開側は、条件の緩い構成向けの攻撃コードが数週間以内、既定の構成向けが 1 か月以内に出ると予測している。記事は対象カーネルのバージョンと修正版を明記しておらず、コンテナ環境への影響も未確認。

**So what**：VPS やクラウド上の VM をホスト側で分離している前提が崩れうる事案で、利用者は自分でパッチを当てるより、事業者の対処状況の確認が先になる。攻撃コードの時期は公表側の予測で、確定ではない。

## 8. example.com が刷新され、プレーンな HTTP のテスト先ではなくなった。IANA は「ウェブサイトは付随物で、挙動に依存しないで」
**一言で**：blog.jxck.io が 10 月 17 日、10 月初めに example.com が作り直され、HTTP の素朴なページを前提にしていた検証がやりにくくなったと書いた。

- 旧サイトは見出しと短い文と IANA へのリンクだけの HTTP ページ。新サイトはダークモード、JavaScript による多言語表示、SVG を備え、HTTPS へリダイレクトされる。Cloudflare 経由で配信され、DNS には AAAA と HTTPS レコードが加わった。
- `telnet example.com 80` で HTTP を教える、ブラウザ警告やキャプティブポータルを試す、コンソールにノイズのない状態で CSS・CORS・iframe を試す、といった使い方が難しくなった。
- 著者が IANA に問い合わせると「example.com は文書用のドメインで、ウェブサイトは付随物。挙動に依存しないで」と回答があり、IANA の VP のブログでも確認された。著者は旧版を `example.jxck.io` に HTTP のまま置き直した。

**So what**：「どこにでもある固定のテスト先」も運営側の都合で変わるという小さな教訓。自分のテストは自分で管理するドメインに置く、という実務的な話。
