## 1. Anthropic が Claude Fable 5.2 と Mythos 5.2 を発表。コーディングと業務ワークフローの指標が大きく伸びた
![](https://www-cdn.anthropic.com/images/4zrzovbb/website/b2dab182c77b4ccfd36423470106915b20f676ae-1200x630.jpg)
**一言で**：Anthropic が 11 月 9 日、同じ基盤モデルの Fable 5.2（全ユーザー向け）と Mythos 5.2（審査を通った組織向け）を公開した。

- Fable 5.2 は FrontierSWE v2 で 69.9%（Fable 5.1 は 56.3%、Opus 5.5 は 62.3%）、業務ワークフローを測る AutomationBench で 51.4%（5.1 は 31.4%）。いずれも Anthropic 自身の公表値。

**So what**：コーディングより「業務ワークフロー」の伸びが大きく、AI に任せる範囲が広がる方向を示す。ただし数字は自社公表なので、第三者の検証（次項のような実測）と併せて見たい。

## 2. 人のレビューを残したまま AI が先に見る：LinkedIn が週 4 万件超の PR を AI でレビュー
![](https://substackcdn.com/image/fetch/$s_!JDQw!,w_1200,h_675,c_fill,f_jpg,q_auto:good,fl_progressive:steep,g_auto/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F35a42d09-7b73-4378-83ed-a907f990eaef_2882x3010.png)
**一言で**：LinkedIn は社内の複数エージェント式 AI レビュアーで週 4 万件以上の PR を処理し、最終承認は人に残している。

- 複数のサブエージェントが互いの結果を見ずに独立にレビューし、一致したものを統合、1 つしか指摘していない項目は別モデルが検証して、確認できたものだけ投稿する。
- 成果の指標は絵文字の反応ではなく「コードが実際に変更された割合」で、採用率は 63.9%（並行性バグと不要コードは 100%、ロジックエラーは 80%）。
- 精度・再現率・時間短縮の数字は未公表で、正解データを構築中。市販ツールはノイズが多く信頼を失った、とも書かれている。

**So what**：「AI が先に見て、人は承認と修正の判断に時間を使う」という分担の実例で、レビューが人の役割として残るという見立てには追い風。ただし誤った指摘を人がどれだけ見抜けるかは記事に数字がない。

## 3. Claude Code の「次回から確認しない」が、秘密情報を公開 GitHub に平文で漏らしていた
![](https://i.nextmedia.com.au/News/crn-690-stock-servers.jpg)
**一言で**：Apiiro の調査で、Claude Code の許可ルール保存の仕様により、DB パスワードや API キーが公開リポジトリの設定ファイルに残っていた。

- 公開 GitHub の約 10 万 4 千件の `.claude/settings.local.json` のうち 1,122 件に実際の秘密情報があり、計 1,379 件。内訳は DB パスワード 379、Supabase の service-role キー 122、SSH ログイン 43、AWS キー 23 など。古い版や履歴まで含めると 2,539 件・1,994 リポジトリ、63 組織に及ぶ。
- 「don't ask again」で承認したコマンドに秘密情報が直書きされていると、そのまま平文で保存される。既存スキャナーの取りこぼしも大きく、gitleaks は 564 件、TruffleHog は 643 件で、215 件はどちらも検出できなかった。
- Anthropic の Boris Cherny 氏は問題を認め、秘密情報スキャンの組み込みなどを検討中。ファイルは自動で gitignore されるので、露出は手動コミットによるものだと主張している。

**So what**：エージェントに権限を渡す運用では、承認の保存先もリスクになる。コマンドに秘密情報を書かず環境変数で参照し、承認はパターン単位にする、という具体策が出ている。

**一言で**：Zenn の検証で、Fable 5.1 から 5.2 への表示額の低下はほぼ単価の差で、キャッシュ書込が起きた回は約 30 倍高くなった。

- キャッシュなしの 1 回目どうしで $0.3907（5.1）→ $0.3053（5.2）、約 78%。入力・出力・キャッシュ読出の単価がすべて 5.1 の 8 割だった。
