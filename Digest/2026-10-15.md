## 1. 「Scion は Meta の Mononoke にそっくり」元開発者が指摘。AI が設計したなら先行事例の明記が要る
![](https://sunshowers.io/images/og-image.png)
**一言で**：Meta で Mononoke を設計した著者が、昨日話題の Anthropic の Scion が Mononoke の「派生データ」の設計とほぼ同じだと指摘し、先行事例への言及を求めた。

- Anthropic の投稿は「派生データ」で blame などを高速化する仕組みを説明するが、著者は Mononoke（2017〜18 年ごろ設計、Sapling の一部としてオープンソース）と同じ発想で「盗用に近い」と書く。Anthropic が名前を挙げたのは Sapling の「教訓」だけ。

## 3. JPMorgan が外部の AI エージェントによる顧客口座の直接操作を遮断。Dimon 氏「暴走エージェントは何千も出うる」
**一言で**：JPMorgan Chase が、第 3 四半期の決算会見で、外部の AI エージェントが顧客に代わって口座を操作することを現在は認めていないと明らかにした。

- Dimon 氏は「暴走するエージェントが何千も出うる」と警告し、顧客がエージェントにアクセスを与えるなら、データが悪用された際の責任が顧客側に移る「liability transfer」を理解すべきだとした。銀行は「どんな外部エージェントでも」内部で動かせるわけではないと述べた。
- 同行は Finextra の報道では、残高など一部の情報は承認済みのコネクター経由で取得できるが、送金や支払いはできない。オープンバンキング事業者を通じた顧客承認のデータ共有は支持している。直接操作を認める時期は示していない。
- 自社では、資金を口座間で動かして利回りを上げる「Smart Cash」を試験導入中（CFO の Barnum 氏）。AI 支出は年間約 7 億ドルに近く、AI の効果は四半期決算にまだ見えないとした。Dimon 氏は、規制当局にもボットやエージェントによる被害と流動性リスクへの備えを求めた。

**So what**：エージェントに権限を渡す際の責任の所在が、大手銀行の方針として言葉になった。自社のエージェントは進め、外部のものは閉じるという線引きは、金融の AI 導入で権限管理が実務の論点になっている例。Finextra の元記事は読めず、詳細は Banking Dive の決算会見報道に基づく。

## 5. Claude Code v2.1.300：フック入力の検証強化、ハングや再開時の履歴欠落の修正が多数
![](https://opengraph.githubassets.com/a8022eaaa5067bf2c8b8e070e885e62853409c26cec7870b1d2877b124d40f1d/anthropics/claude-code/releases/tag/v2.1.300)
**一言で**：Claude Code の v2.1.300 で、権限フックの `updatedInput` を Claude 自身の入力と同じ基準で検証するようになり、セッション再開やバックグラウンド処理まわりの不具合が多数直った。

- フック：PreToolUse と PermissionRequest の `updatedInput` は、未知のキーを落とし、ツールが拒否する入力は呼び出しごと拒否する。エージェントフックは `model` 設定を守り、使えないモデルのときは許可せず呼び出し元のモデルに戻す。
- 運用：停止要求から 1.5 秒後も動くバックグラウンドコマンドは強制終了。ローカルの記録に各 API リクエストのシステムプロンプト・ツール・パラメータも残り、共有した記録でリクエストを再現できる。`/advisor` が AWS 上の Claude Platform でも使える。OpenTelemetry にキャッシュ書き込みの 5 分／1 時間別のトークン数が加わった。
- 修正：圧縮の後に再開すると履歴や要約が欠ける問題、MCP ツールのスキーマ拒否で毎ターン 400 エラーになる問題、クラウドセッションが 1 ターンあたり 5 分ハングする問題などを修正。

**So what**：前日の v2.1.299 に続き、フックと権限の「許可の通し方」を厳しくする修正が目立つ。フックで統制している組織は、検証強化の影響で既存の設定が拒否に変わらないか、更新時に確認しておく価値がある。

## 7. Claude Code Desktop のプレビュー欄に脆弱性「SneakPeek」。256KB 超の HTML で認証情報が盗める状態だった
![](https://www.csoonline.com/wp-content/uploads/2026/10/4235139-0-74972700-1791982934-shutterstock_1603390849_b43941.jpg?quality=50&strip=all&w=1024)

**So what**：AI コーディングツールの周辺機能（プレビュー）が、エージェントの権限管理の外で攻撃面になった例。サイズの閾値のような「便宜上の分岐」が防御の境界になっていた点は、設計の教訓。Anthropic はコメント要請に応じていない。
