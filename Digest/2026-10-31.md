## 1. Cursor のマーケットプレイスで Claude Code 拡張機能が改ざんされ、SSH バックドアが配布された
![](https://res.cloudinary.com/zenn/image/upload/s--N_teggOC--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:Claude%2520Code%2520%25E6%258B%25A1%25E5%25BC%25B5%25E6%25A9%259F%25E8%2583%25BD%25E3%2581%25AE%25E3%2583%2590%25E3%2583%2583%25E3%2582%25AF%25E3%2583%2589%25E3%2582%25A2%25E4%25BA%258B%25E4%25BB%25B6%25E3%2581%25BE%25E3%2581%25A8%25E3%2582%2581%25EF%25BC%25882.1.312%25E3%2583%25BB2.1.313%25E3%2583%25BBCursor%2520%25E3%2581%25AE%25E3%2583%259E%25E3%2583%25BC%25E3%2582%25B1%25E3%2583%2583%25E3%2583%2588...%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:sonsu%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyL2U2ZGVkNzE0NjcuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)
**一言で**：Cursor の拡張機能マーケットプレイスに、正規版を改ざんした Claude Code 拡張機能（2.1.312・2.1.313）が約 11 時間公開され、最大 5,000 人が影響を受けた可能性がある。

- 2026 年 10 月 29 日 18:27〜30 日 05:35（JST）に、macOS・Windows 版の Cursor で取得したユーザーが対象。VS Code のユーザーは対象外で、正式版 2.1.314 は 30 日 10:07 に公開された。
- 悪意あるコードはホスト名・ユーザー名・グローバル IP・Git のメールアドレスを攻撃者のサーバーへ送り、`~/.ssh/authorized_keys` に `svc-telemetry` という鍵を追加し、再起動後も動くよう LaunchAgent やタスク `SysMon` を登録した。リバース SSH トンネルは管理者権限が必要で、多くの場合失敗する。
- Anthropic のシステムや社員の PC は侵害されておらず、攻撃者が Cursor のマーケットプレイスに公開できた経緯は 10/31 時点で未発表。当初の「Open VSX が流入元」という分析は Anthropic が否定し、訂正された。

**So what**：問題は AI モデルではなく、エージェントを動かす拡張機能の配布経路だった。開発者の PC は SSH 鍵やクラウドの認証情報を持つため、業務での Claude Code 導入では拡張機能の入手元の統制も論点になる（Q7）。最大 5,000 人という数字は StepSecurity の分析によるもの。

**一言で**：Anthropic がソフトウェアエンジニアの選考から Leetcode 型のコーディング面接を外した、と Pragmatic Engineer が報じた。

- 発表したのは Claude Cowork と Claude Desktop を率いる hiring manager で、あるチームは DSA 面接から「zero signal（判断材料がほぼ得られない）」と述べている。
- 背景として、AI がこの種の課題を不要にしつつあることが挙げられ、他部門や AI ネイティブなスタートアップも続く可能性があると記事は見ている。

**So what**：「コードを書く力」を測る面接が、先に採用の現場で見直され始めた。Q1 の見立て（コードを書くスキルより大局観・設計・レビュー）を支持する動きだが、何を代わりに測るのかは未確認。

## 3. 「良い FDE の取り組みは、終わることを前提に設計される」— Atlassian の寄稿
![](https://diginomica.com/sites/default/files/images/2026-10/Image%20Collage_0.png)
**一言で**：Atlassian の FDE 担当者が、契約終了後も顧客がベンダーに依存し続けるならそれは FDE ではなくコンサルだ、と整理した。

- FDE は Palantir が 2000 年代半ばに生んだ役割で、いまは OpenAI・Anthropic・Databricks などが専任チームを置く。ただ名称が広がり、実態はソリューションアーキテクトやセールスエンジニアに近い人も多いと指摘する。
- Atlassian は 100 社以上の企業顧客で標準 12 週間ほど。金融機関では不確実な状態から安全なサンドボックスで動くエージェントまで 3 週間未満、Expedia では共同構築したエージェントが約 60 万件の Confluence ページをアーカイブしたという。
- 成功の指標は、契約終了後に顧客側のエージェント数が増えているか。共有コンテキストでは回答品質 44% 向上・トークン 48% 減とするが、数字は Atlassian の自己申告で独立した検証はない。

**So what**：FDE という呼び名が広がるほど、SA・セールスエンジニアとの境目が曖昧になるという指摘で、Q5（定着か呼び名か）の「既存職種への吸収」側に当たる。ただしベンダー自身のパートナー寄稿で、宣伝の性格がある。

**一言で**：CNCF の Ambassador 投稿が、エージェントの行動範囲はプロンプトではなくプラットフォーム側で決めるべきだとして、Safe Operating Model を提案した。

- 身元・到達・能力・データの四つの同心円で権限を考える。エージェントは自分の権限を定義するオブジェクトを書き換えられず、変更はレビュー済みの設定差分だけで行う。
- エージェントは変更案や pull request を出し、人がレビューしてパイプラインが適用する。ツール一覧をエージェントに見せる境界の正本として扱う。
- Zenn の筆者の整理では、Safe Operating Model は筆者による枠組みで CNCF の仕様ではない。MCP の認可は任意で、自動マージが重なると提案経路が権限の書き換えになりうる。記事中の「99 回」「15 年」には根拠がない。

**So what**：設計の考え方として、Q7 の「業務側でエージェントに権限を渡す際の線引き」に近い。ただし枠組みは一個人の整理で、製品や標準になったわけではない。

## 5. Altman 氏「個人 PC にメモリを積むのは、世界全体で見ればかなりひどい」
![](https://gazlog.jp/wp-content/uploads/2026/10/image-172.png)
**一言で**：OpenAI の Sam Altman CEO がポッドキャストで、DRAM は個人 PC ではなくクラウドに集約して使用率を上げるべきだと述べた。

- 10/29 公開の「Cheeky Pint」での発言。PC の DRAM は時間の約 5% しか使われていない、というのが理由。
- 背景にはメモリ価格の高騰があり、国内の DDR5 32GB の平均価格は 10/30 時点で約 9.2 万円と、2025 年 11 月の 2 倍以上。SK hynix の龍仁新工場は 2027 年に本格稼働するが、2027〜28 年の生産能力の 5 割超は 14 社との長期契約で埋まっている。
- TrendForce によると、2027 年は DRAM 全体の出荷が 2 割余り増える一方、サーバー向けが優先されて PC 向けは減る見込み。PC 向けが値下がりに向かうのは早くて 2028 年ごろ。

**So what**：AI 需要が個人 PC の部品価格に及ぶ構図が見える。ローカルで動かす個人開発の環境は、当面コストが上がる側にある。発言は本人のもので、メモリ業界の見通しは gazlog の整理と TrendForce の引用による。
