# Karpathy が2時間で作った HackerTube：HN で推薦された YouTube 動画6,454本のサイト

![](https://bearblog.dev/static/og-image.png)

> [!summary] 一言で
> Karpathy が、Hacker News のコメントで推薦された YouTube 動画を集めた「HackerTube」を、Claude Code で約2時間かけて作った。

- 約4万件の HN コメントから推薦動画を抽出し、スパム除去まで進めた結果、2007〜2026年の6,454本・150トピックが残った。
- 人の手作業は YouTube API キー、VPS、ドメインの用意の3点だけ。デプロイ・セキュリティ・最適化は Claude が担当した。

> [!tip] So what
> 小さな個人プロジェクトなら、データ収集から公開まで人間が環境の準備だけをする形が成立している例。Q7 の個人開発側の事例として見られる。
