# Claude Code に「他人のゲームの再現」を避けるルール、Anthropic が追加を認める

![](https://eu-images.contentstack.com/v3/assets/blt740a130ae3c5d529/blta970312a7256ca55/6ae4e702d996de0029eee354/claudeiconfeatured.jpg?disable=upscale&width=1200&height=630&fit=crop)

> [!summary] 一言で
> Claude Code が 10 月 27 日ごろから、特定の既存ゲームの再現を作らないよう誘導されるようになり、Anthropic が Opus 5.5 の更新としてプロンプトに 2 文を足したと認めた。

- ユーザー報告のルールは「名前を変えたり『オリジナル』と呼んでも、特定の既存ゲームを作らない」という趣旨で、無効にする方法はないとされる。オリジナル、ジャンルが同じゲーム、自作のデザインや素材を使ったゲームは引き続き作れる。
- Anthropic 広報は技術スタッフ Addy Osmani 氏の X 投稿を案内し、IP の侵害に Claude を使うことは利用規約に反すると説明。バランスは今後も調整するとした。
- Game Developer は、言い回しでの回避が可能なこと、素材の所有をソフトが判断できないこと、制限のないオープンウェイトモデルへの移行を課題に挙げた。背景には、AI による複製を恐れて公開テストを中止したインディースタジオがある。

> [!tip] So what
> ツール側が出力の内容に介入する例。Claude Code を使う仕事では、モデルの更新で「できていたことが変わる」前提で見ておく必要がある。
