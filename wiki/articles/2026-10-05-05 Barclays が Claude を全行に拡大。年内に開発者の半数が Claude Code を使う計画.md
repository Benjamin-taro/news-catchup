# Barclays が Claude を全行に拡大。年内に開発者の半数が Claude Code を使う計画

> [!summary] 一言で
> Barclays が 10 月 1 日、Anthropic との協業を拡大し、年末までに開発者の半数、2027 年末までに大半が Claude Code を使う計画を明らかにした。

- 英国の全従業員向け「Colleague Knowledge Assistant」は 16,000 人超が利用し、2025 年以降で 100 万件超の検索を処理。
- グローバル・マーケッツ部門では、Claude が顧客からのメール 1 日約 12 万通の処理を支援している。
- 用途はレガシー基盤の刷新、ソフトウェア品質の向上、運用効率化。

> [!tip] So what
> 大手銀行が「試験導入」ではなく開発者の半数という数値目標を置き、レガシー刷新まで任せ始めた。国内の銀行にとっても、導入規模の目安になる事例。
