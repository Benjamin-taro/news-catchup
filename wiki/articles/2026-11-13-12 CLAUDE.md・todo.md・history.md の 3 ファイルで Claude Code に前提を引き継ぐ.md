# CLAUDE.md・todo.md・history.md の 3 ファイルで Claude Code に前提を引き継ぐ

> [!summary] 一言で
> 会話が終わると文脈を失う Claude Code に、役割の違う 3 つの md ファイルで前提を渡す運用が Zenn で紹介された。

- `CLAUDE.md` は入口としてルールと資料の場所だけ、`todo.md` は未完了タスク、`history.md` は完了作業と判断の経緯を積む。ルールには理由や過去の失敗を添える。
- `todo.md` のずれは、未完了一覧を生成するスクリプトと、一覧に漏れがあれば失敗するテストで防ぎ、作業の最後に実行させる。
- 効果は、同じ指示の繰り返しの減少、チーム全員で同じルールで動くことなど（定量の数字はない）。

> [!tip] So what
> チームで使う場合の前提そろえの具体例。数字による効果測定がない点は割り引く。
