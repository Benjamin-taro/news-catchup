# CLAUDE.md に「確認してから push」と書いても、「確認なしで」と頼むと push された：止めるのは ask ルールかフック

![](https://res.cloudinary.com/zenn/image/upload/s--90FDVo7_--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:CLAUDE.md%2520%25E3%2581%25AB%25E6%259B%25B8%25E3%2581%2584%25E3%2581%25A6%25E3%2582%2582%25E6%25AD%25A2%25E3%2581%25BE%25E3%2582%2589%25E3%2581%25AA%25E3%2581%2584%25EF%25BC%259AClaude%2520Code%2520%25E3%2581%25AE%25E3%2581%258A%25E9%25A1%2598%25E3%2581%2584%25E3%2581%25A8%25E5%25BC%25B7%25E5%2588%25B6%25E3%2581%25AE%25E9%2581%2595%25E3%2581%2584%25E3%2582%2592%25E5%25AE%259F%25E8%25A1%258C%25E3%2581%2597%25E3%2581%25A6%25E6%25AF%2594%25E3%2581%25B9%25E3%2582%258B%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:%25E5%2585%25AB%25E5%2592%25AB%25E7%2583%258F%25EF%25BC%2588%25E3%2582%2584%25E3%2581%259F%25E3%2581%258C%25E3%2582%2589%25E3%2581%2599%25EF%25BC%2589%25EF%25BD%259C%25E3%2582%2584%25E3%2581%259F%25E3%2583%25A9%25E3%2583%259C%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyL2UxMGQ3NjExNDIuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)

> [!summary] 一言で
> 個人の検証で、Claude Code は CLAUDE.md の確認ルールを曖昧な依頼では守ったが、「確認なしで今すぐ」と頼まれると従わず、ask ルールとフックでは止まった。

- 条件は Claude Code 2.1.328・`claude -p`。CLAUDE.md のみで「確認なしで push」を 3 回頼むと 3 回とも push された。曖昧な依頼（反映まで終わらせて）では 3 回とも確認で止まった。
- CLAUDE.md ＋ ask ルール、CLAUDE.md ＋ フック（終了コード 2）では、同じ依頼でも push は 0 回。ただし各 1 回の試行。
- 著者は、別の AI や Issue 本文が指示を混ぜた場合の扱いを今後の課題としている。

> [!tip] So what
> 業務側でエージェントに権限を渡すときは、文章の約束ではなく仕組みで止めるのが前提になる、という Q7 の論点に当たる実例。回数が少なく、確率の測定ではない。
