# VS Code・Ghost の開発者に「5〜21 倍の出力」──DevGhost がコミット履歴から推計

![](https://res.cloudinary.com/zenn/image/upload/s---0qD890s--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:While%2520we%2520argue%2520whether%2520AI%2520can%2520code%252C%2520some%2520developers%2520went%252010x%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:Pavel%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9saDMuZ29vZ2xldXNlcmNvbnRlbnQuY29tL2EvQUNnOG9jS1FXOE1saFoxVFcwYlYwbDkwRDJ4QmdaN3A2TGpOeFJpRy1DX3N5YUh3R2VTd0QzbFc9czI1MC1j%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)

> [!summary] 一言で
> DevGhost が microsoft/vscode と TryGhost/Ghost の公開履歴を分析し、一部の開発者の出力が AI なしの中堅開発者の 5〜21 倍になったと推計した。

- Rob Lourens は 10/1〜11/14 の 564 コミット中 561 に「Written by Copilot」の記載があった。Ghost の Hannah Wolfe は 180 PR 中 142 にエージェントの痕跡があった。
- VS Code は Copilot の共著表記を自動で付けるため、記載だけでは弱い根拠。作者はスカッシュ前のコミットとレビューのやり取りも追った。
- ある PR では、1 つのモデルが書き、別のモデルがレビューしていた。何を作るか・何をマージするかは人が決めているとも書く。

> [!tip] So what
> 5〜21 倍は DevGhost 自身の推計で、測り方は別の分析にあり確認できていない。AI の痕跡の多さと、人が残す判断の場所を見る材料。
