# X の声：日本の全法令を git の履歴にした人、「git log で法律が読める」

![](https://lh3.googleusercontent.com/J6_coFbogxhRI9iM864NL_liGXvsQp2AupsKei7z0cNNfDvGUmWUy20nuUhkREQyrpY4bEeIBuc=s0-w300-rw)

> [!summary] 一言で
> X に、日本の全法令を 1 法令 1 ファイルで git 管理し、改正法の施行を 1 コミットにした人の話題が出ている。

- 個人情報保護法の log を見ると、無関係に見える法律の改正に巻き込まれて書き換わっているのが見える、という内容。
- 投稿者は「git log で法律が読める時代」と書き、法学部の友人に教えたとしている。
- 個人の投稿で、元リポジトリや規模は確認できていない。

> [!tip] So what
> エンジニアの道具（バージョン管理）が、法令の読み方という別領域に使われる例。法務のテクノロジーとして、改正の影響範囲を機械的に追える可能性を示す。投稿者の詳細は未確認。
