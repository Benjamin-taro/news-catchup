# OpenAI の Agents SDK チームのエンジニアが、社内の会議室に録音機器を仕掛けた疑いで逮捕。FBI・司法省が関与

![](https://substackcdn.com/image/fetch/$s_!I8Qf!,w_1200,h_675,c_fill,f_jpg,q_auto:good,fl_progressive:steep,g_auto/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F722b7b9e-4a5d-412c-9aa3-22019bcf0c2d_2048x1444.png)

> [!summary] 一言で
> The Pragmatic Engineer の Pulse #195（10 月 15 日）が、OpenAI の Agents SDK チームの社員が、社内の会議室に秘密の録音機器を仕掛けたとして逮捕されたと伝えた。

- FBI と米司法省が関与している。無料の冒頭部分では、捜査の詳細までは書かれていない。
- 同じ号では、Anthropic が Git から移った理由と経緯の内側の話、ビッグテックの採用で AI を使うコーディング面接が増えている動きも扱う。
- 本文の大半は有料で、読めたのは公開されている冒頭のみ。

> [!tip] So what
> 大手 AI 企業の内部統制と人事の問題が、逮捕という形で表に出た。動機や被害の中身は不明で、現時点では事実関係の確認が先。有料のため冒頭だけを根拠にしている。
