# Claude Code に作らせた PHP 問題 433 問を実行して照合：不一致 0、ただし 10 問が漏れていた

> [!summary] 一言で
> mugen_web 氏が、Claude Code が作った PHP 初級問題の正解を実際に実行して確かめ、検証自体の抜けを見つけた。

- 500 問のうちコードを含む 433 問を PHP 8.2.0 で実行して正解と照合し、一致は 396 から 403 に増え、不一致は 0。
- 出力を問う 10 問が、本文の書き出しの違いで照合対象から漏れていた。振り分けを直して 7 問を照合し、すべて一致。照合に使う手元の DB が問題の JSON より古いという別の問題もあった。
- 実行では見つからない不備（正解だけ長い選択肢が 3 問、本文に答えのヒントがある問題が 4 問）は、著者が読んで見つけた。

> [!tip] So what
> 「テストが通った」は検証の網が正しいときだけ意味を持つ。AI が作ったものに実行検証を付けても、網の漏れと、実行では測れない質は人が見る必要がある。
