# MCP に「Skills over MCP」。ツール提供元がスキルも配れるように

![](https://www.publickey1.jp/2026/skills-over-mcp-beta.png)

> [!summary] 一言で
> Anthropic が MCP の新機能 Skills over MCP をβ提供し、サーバがツールと一緒に「使い方のスキル」を配布できるようになった。

- これまでスキル（SKILL.md など）はエージェントの実行環境に個別に置く必要があり、ツールが更新されてもスキルが古いままになる問題があった。
- 新機能ではエージェントが MCP 経由でサーバから最新のスキルを取得し、必要なときだけ読み込むのでコンテキストを節約できる。
- Claude と Claude Code の Pro・Max・Ultra プランでは既定で有効。

> [!tip] So what
> 業務手順書としての Skills を「各自が手元に置く」から「ツール提供元が更新して配る」へ移す動き。社内ツールを MCP で出す側は、スキルも同じ場所で保守する設計を考える段階に入る。
