# Claude Code を社内に入れるための「申請書・回答表・管理設定」一式が Zenn の有料本に

![](https://res.cloudinary.com/zenn/image/upload/s--SKTL9MF2--/g_center%2Ch_280%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYm9va19jb3Zlci80OTI1Njg2Nzg3LnBuZw==%2Cw_200/v1627283836/default/og-base-book_yz4z02.jpg?_a=BACMTiAE)

> [!summary] 一言で
> 導入担当者向けに、稟議の雛形、情シス向けの回答表、3 段階の管理設定、設定確認スクリプトをまとめた本が公開された（1,500 円）。

- 試験利用・チーム・全社の 3 段階の managed-settings.json の雛形と、実際に制限がかかっているかを判定する確認スクリプトを含む。
- 社内ガイドラインへの追加条文案 12 項目、例外申請や変更記録、版更新時の再確認などの運用書式もある。
- 検証は Claude Code 2.1.294 / 2.1.296 が対象で、試していない点は未検証と明記。全 9 章（約 54,000 字）のうち 2 章は無料で、設定の中身は無料部分には出ていない。

> [!tip] So what
> 業務側がエージェントに権限を渡すには、申請・設定・確認の文書づくりが必要で、その型が商品になりつつある。内容の質は有料部分なので未確認。
