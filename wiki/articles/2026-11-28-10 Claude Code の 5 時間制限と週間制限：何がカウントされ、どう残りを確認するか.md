# Claude Code の 5 時間制限と週間制限：何がカウントされ、どう残りを確認するか

> [!summary] 一言で
> Zenn の記事が、Claude Code の 5 時間枠と週間枠の仕組みと、残量の確認方法を 2026 年 11 月時点で整理した。

- 5 時間枠は最初のメッセージから 5 時間でリセット。週間枠は 7 日単位でアカウントごとの固定日時にリセットされ、Max と Ultra にはモデル別の週間枠もある。
- claude.ai・Claude Code・Desktop・スマホ・IDE 拡張は同じ枠から減る。API キーが環境変数にあると従量課金になる。
- 確認は `/usage`、設定の使用量画面、ステータスラインの `rate_limits`。節約策は `/clear`、定型作業の Sonnet 化、不要な MCP の無効化など。末尾は著者の macOS アプリの紹介。

> [!tip] So what
> 複数セッションを並行させる使い方では、枠の消費が運用上の制約になる。公式ヘルプの説明の整理が中心で、新しい発表ではない。
