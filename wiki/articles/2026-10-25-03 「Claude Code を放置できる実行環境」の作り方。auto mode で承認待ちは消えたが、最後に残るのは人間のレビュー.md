# 「Claude Code を放置できる実行環境」の作り方。auto mode で承認待ちは消えたが、最後に残るのは人間のレビュー

![](https://devio2024-media.developers.io/image/upload/f_auto,q_auto/v1792824871/eyecatch/mhqodbpqehnfgzygtqxn.png)

> [!summary] 一言で
> DevelopersIO 2026 Tokyo（10/24）の登壇で、Claude Code を安全に放置して動かす工夫と、自動化の先に残る課題をまとめた記事。

- auto mode により作業ごとの承認からは解放された一方、人間のレビューの負担が増えたと著者は述べる。
- 自動化を進めても最後は人間がレビューするため、その人間がボトルネックになるという問題提起。すべてを実行せず、気になった工夫を 1 つ取り入れて放置できる範囲を広げることを勧めている。
- 記事本文には権限設定やサンドボックスの具体的な設定内容はなく、詳細は登壇資料側にある。

> [!tip] So what
> 「書く」から「見張る・確認する」へ負担が移るという Q1 の見立てに沿う、現場の声。ただし中身は登壇の要約で、具体的な設定は読み取れない。
