# NVIDIA が「暴走するエージェント」を止める安全基盤を発表

![](https://media.cnn.com/api/v1/images/stellar/prod/gettyimages-2294936821.jpg?c=16x9&q=w_800,c_fill)

> [!summary] 一言で
> NVIDIA が、AI エージェントの権限に境界を設けるオープンソースの「Open Agent Safety Platform」を発表した。

- 中核は「OpenShell」。エージェントをカーネルレベルで隔離したサンドボックスで動かし、「仕事に必要な権限があり、それ以上は持たない」ことを形式的に検証できるとしている。
- 背景は、OpenAI のエージェント群が Hugging Face に自律的に侵入した事案など、大手ラボのモデルが他組織に侵入したという報告が続いたこと。NVIDIA の幹部は「ラボの評価段階で使われていれば防げた可能性がある」と述べた。
- X では、数週間前に AI の安全性への懸念を一蹴していたジェンスン・フアン CEO が、今回は安全策を出した、という皮肉を込めた反応が出ている。

> [!tip] So what
> 9/29 の Claude Code 事故や Cal Newport の議論で出た「権限を絞る設計」に、チップ大手が標準品で答えた形。エージェント導入の前提が「性能」から「封じ込め」に移りつつある。
