# Meta と Microsoft が社内の Claude 利用を絞り込み。Microsoft は月間 AI 支出の上限を 10 万ドルから約 1 万ドルに

![](https://cdn.rswebsols.com/wp-content/uploads/2025/10/otr1by4mkru.jpg)

> [!summary] 一言で
> The Information の報道によると、Meta と Microsoft が自社ツールや別製品への移行を進め、従業員の Claude 利用を減らしている。

- Microsoft は Anthropic 関連の社内支出見込み（年 10 億ドル超）を 3 分の 1 以上縮小し、クラウド・AI 部門の従業員 1 人あたり月間 AI 支出の上限を 10 万ドルから多くの場合約 1 万ドルに下げた。ただし記事は、上限であって実際の支出ではないと補足している。
- Meta の Claude Code 利用者は年初の約 6 万人から約 3 万人に減った。主因はレイオフではなく、自社製の MetaCode（社内 3 万人超）と Muse Code（6,000 人超）への移行とされる。
- Microsoft は GitHub Copilot や OpenAI への移行を促す一方、顧客向けの Claude 提供は続ける。Anthropic の年換算売上ペースは 650 億ドルとされる。

> [!tip] So what
> 大手が自社のコーディングエージェントに寄せ始め、AI ツールのコスト管理が経営課題になっている様子がうかがえる。報道の二次記事に基づく数字で、一次情報は確認できていない。
