# 「1 か月 Claude Code と伴走して疲れ果てた」投稿に、はてブで共感と対処が集まる。作業時間は縮んでも、指示・レビュー・判断の負荷は別物

![](https://s.tgstc.com/ogp3/255e970e164822aa11c4f1b3c8e194ef-1200x630.jpeg)

> [!summary] 一言で
> Posfie の投稿が、Claude Code を育てながら使ううちに強いストレスを感じ「AI をやめたい」と書き、はてブで人気になった。

- 投稿者は完璧主義で、指示と違う動きをされると強い言葉で責めてしまい、人には向けない言い方をする自分に違和感を持つ。「AI 利用＝怒り」の結びつきが定着し、働くこと自体がつらくなるのを心配している。ただ、AI を使わずに働く道は現実的でないとも書く。
- 反応は 3 方向。①細部を諦めて大枠で良しとする、8 割を任せて仕上げは手で、②人なら「忙しいから」と流せるが AI には情状酌量が効かず苛立つ、Codex のほうが指示に忠実という声、③「新入社員に読み替える」「完璧を求めると萎縮して質が落ちる」「管理の細かい性格かで向き不向きが分かれる」。
- 負荷の質への指摘もある：作業時間が短くなっても、指示・レビュー・判断の認知負荷は別で評価に入れるべきだ、返答が速すぎて休む間がない、という意見。

> [!tip] So what
> AI で生産性が上がるかどうかとは別に、人の側の消耗（レビュー・判断の連続、完璧主義）が働き方の論点になっていることを示す。個人の体験とコメントの集まりで、一般化できるデータではない。
