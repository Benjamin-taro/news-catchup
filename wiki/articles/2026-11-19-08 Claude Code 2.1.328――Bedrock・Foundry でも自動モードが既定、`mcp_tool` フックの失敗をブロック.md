# Claude Code 2.1.328――Bedrock・Foundry でも自動モードが既定、`mcp_tool` フックの失敗をブロック可能に

![](https://opengraph.githubassets.com/cb956e0313e453d1ba5080e2bb2510ad156dcebf68610b6ec5e7618b48f0d4e6/anthropics/claude-code/releases/tag/v2.1.328)

> [!summary] 一言で
> Claude Code が、Amazon Bedrock・Google Cloud・Microsoft Foundry で Opus 4.6／Sonnet 4.6 の自動モードに対応した。

- 権限モードを指定しない対話セッションは自動モードで開始する。
- `mcp_tool` フックに `"onFailure": "block"` を追加。呼び出しに失敗したらアクションを止められる。
- `/code-review` は多くのモデルでバグと CLAUDE.md 違反だけを報告するようになり、整理は `/simplify` に分かれた。サンドボックスが起動できないときは、次のサンドボックス付き Bash コマンドを拒否する。

> [!tip] So what
> クラウド経由で使う企業環境にも、エージェントへ権限を渡す既定の動きが広がる。権限の既定値が変わるので、導入側は設定の確認が要る。
