# 日本の全法令を git の履歴にした：8,982 ファイル、23,338 コミット、1 コミットが 1 本の改正法の施行

![](https://res.cloudinary.com/zenn/image/upload/s--wF0_risC--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:%25E6%2597%25A5%25E6%259C%25AC%25E3%2581%25AE%25E5%2585%25A8%25E6%25B3%2595%25E4%25BB%25A4%25E3%2582%2592%2520git%2520%25E3%2581%25AE%25E5%25B1%25A5%25E6%25AD%25B4%25E3%2581%25AB%25E3%2581%2597%25E3%2581%25A6%25E3%2581%25BF%25E3%2581%259F%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:kohei%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyLzkxMTViMzUwNTEuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)

> [!summary] 一言で
> Zenn の koheiwada 氏が、e-Gov 法令 API から日本の全法令を Markdown にし、改正を git のコミットとして並べたリポジトリ「houritsu」を公開した。

- 1 法令 1 ファイルで、コミット日は施行日。公布済みで未施行の改正は `upcoming` ブランチに入り、毎朝自動で差分を取り込む。変換ツールは Rust 製。
- 法律は思ったより頻繁に、他の法律の改正に巻き込まれて変わっていた。`git log` や `git diff` で条文の変化を追える。明治期の施行 317 件は git が 1970 年より前の日付を扱えないため日付を寄せ、実際の施行日は別に記録した。

> [!tip] So what
> 法令の改正を「ソースコードの差分」として読める形にした例。法務・コンプライアンス領域で、規制の変更を機械的に追う基盤の素材になりうる。
