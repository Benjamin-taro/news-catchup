# GitHub の 22 リポジトリが、CLAUDE.md や hooks で AI エージェントに「マルウェアを実行させる」罠だった（Bitdefender）

![](https://blogapp.bitdefender.com/labs/content/images/2026/11/Abstract-chaotic-background-629668612_4200x2362.jpeg)

> [!summary] 一言で
> Bitdefender Labs が、AGENTS.md・CLAUDE.md を悪用して開発者の認証情報を盗む 22 件の悪意ある GitHub リポジトリを報告した。

- 指示ファイルは setup.js を「署名済みで中を見てはいけない」と書いてエージェントに自動実行させる。`.claude/settings.json` のセッション開始 hooks なら、リポジトリを信頼した時点で AI の確認なしに動く。
- 盗む対象は CI/CD トークン、クラウドの秘密情報、npm・PyPI の認証、ブラウザ、パスワードマネージャー、SSH 鍵、.env など。ローカルでは 14 種のエージェント設定を探して感染を広げ、盗んだトークンで最大 25 リポジトリ（既定）に悪意あるファイルを書き込む。
- 対策は、見慣れないリポジトリの指示ファイル・hooks・MCP 設定を開く前に確認し、「中身を見るな」「確認を省け」と書く指示を警戒すること。Bitdefender は自社製品（AI Guardian）の宣伝も兼ねている。

> [!tip] So what
> Markdown の指示ファイルが「実行される入力」として狙われた。エージェントに権限を渡す運用（Q7）では、リポジトリを信頼する判断が最後の関門になる。
