# Claude Code に無人で記事とコードを push させる運用の「検査一式」。約 150 行・18 秒、人のレビューの代わりに毎回走る 10 種

![](https://res.cloudinary.com/zenn/image/upload/s--GuHzWsp3--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:Claude%2520Code%2520%25E3%2581%25AE%25E5%25A4%2589%25E6%259B%25B4%25E3%2582%2592%2520CI%2520%25E3%2581%25A7%25E6%25AD%25A2%25E3%2582%2581%25E3%2582%258B%25E6%25A4%259C%25E6%259F%25BB%25E4%25B8%2580%25E5%25BC%258F%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:%25E3%2582%25A2%25E3%2582%25BB%25E3%2583%25AD%25E3%2583%25A9%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyL2FmOTgyYjM3NzMuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)

> [!summary] 一言で
> Claude Code に公開まで任せる著者が、秘密情報・公開時刻・コードと原本の照合などを機械的に止める CI の作りと限界を書いた。

- push 前のローカル、push ごとの CI、毎日の外部確認の 3 段構成。検査は `check.sh` に約 150 行で 10 種あり、約 18 秒で終わる。フックのテストは 39 件、Web ツールの判定テストは 33 件。
- 公開時刻の歯止めは当初 48 時間先を要求したが、正しい手順でも毎回落ちたため 2 時間に変更。「毎回落ちる検査は検査ではない」という教訓を挙げる。エラーには直し方を書き、無人のセッションが自分で直せるようにした。
- 限界も明記：検査スクリプトが同じリポジトリにあり、AI が検査自体を書き換えれば通ってしまう。秘密情報の検出は決まった形しか拾えない。

> [!tip] So what
> 「レビューを人がやる」代わりに、事故の型を機械的な検査に落とす実例。Q1 の「レビューは人間に残る」という見立てに対し、型が決まった事故の検知は自動化できるが、検査を書く側の設計と権限は人に残る、という両面が見える。個人の運用記録である点に注意。
