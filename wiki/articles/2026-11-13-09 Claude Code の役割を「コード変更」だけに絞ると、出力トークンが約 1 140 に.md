# Claude Code の役割を「コード変更」だけに絞ると、出力トークンが約 1/140 に

![](https://res.cloudinary.com/zenn/image/upload/s--xRodNt23--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:Claude%2520Code%25E3%2582%2592%25E8%25A8%2598%25E4%25BA%258B%25E3%2581%25A5%25E3%2581%258F%25E3%2582%258A%25E3%2581%258B%25E3%2582%2589%25E5%25A4%2596%25E3%2581%2597%25E3%2581%259F%25E3%2582%2589%25E3%2580%2581%25E5%2587%25BA%25E5%258A%259B%25E3%2583%2588%25E3%2583%25BC%25E3%2582%25AF%25E3%2583%25B3%25E3%2581%258C%25E7%25B4%2584140%25E5%2588%2586%25E3%2581%25AE1%25E3%2581%25AB%25E3%2581%25AA%25E3%2581%25A3%25E3%2581%259F%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:kosuke%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyLzJhNzBjYjEyN2IuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)

> [!summary] 一言で
> 個人サイトの運用で、記事づくりを別のエージェントと Codex に移したところ、Claude Code の出力トークンが 589 万から 4.2 万に減った。

- 2026-10-30 の前後で、出力トークン 5,899,323 → 41,663、セッション 145 → 13、API 応答 7,642 → 114。同じ応答が `message.id` で重複記録されるため、重複を除かないと約 2.5 倍に過大計上される。
- 変更後の 13 回は、記事登録のデータ追加 6、デザイン・機能変更 4、表示バグ 2、セキュリティ修正 1。記事数は 1 日 2.5 本から 2.3 本へ微減。
- 筆者自身が、他エージェントの使用量や品質は未計測で、対照実験ではないと明記している。

> [!tip] So what
> 「何に利用枠を使っているか」はログから測れる。ただし全体コストの比較ではなく、節約の根拠としては限定的。
