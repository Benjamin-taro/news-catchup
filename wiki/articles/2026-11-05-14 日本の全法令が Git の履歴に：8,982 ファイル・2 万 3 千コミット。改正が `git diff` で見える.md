# 日本の全法令が Git の履歴に：8,982 ファイル・2 万 3 千コミット。改正が `git diff` で見える

![](https://forest.watch.impress.co.jp/img/wf/list/2153/621/image_top.png)

> [!summary] 一言で
> Kohei Wada 氏が、法令を Markdown にして改正ごとにコミットするリポジトリ「houritsu」を公開した。

- 法令ファイルは 8,982、main のコミットは 23,338。改正法 1 本の施行を 1 コミットとし、公布済みで未施行のものは `upcoming` ブランチに置く。e-Gov から毎朝差分を取って追加する。
- 履歴は e-Gov が提供する 2015 年ごろ以降が中心。データは CC BY 4.0、変換プログラムは Rust 製で MIT。
- Git の弱点は 1970 年より前の日時をコミットに指定できない点で、日時は 1970 年 1 月 2 日に置き換え、本来の施行日はメタデータに残した。

> [!tip] So what
> 法改正の追跡を開発の道具で扱える形にした例で、法務・コンプライアンス領域の技術にも使える素材。個人の公開物で、法的な正確さの保証は記事にない。
