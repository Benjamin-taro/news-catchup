# Nadella が Pragmatic Engineer で語る「コードが安くなった後」──ボトルネックは検証、Microsoft は初めて大半のエンジニアに早期退職を提示

![](https://substackcdn.com/image/youtube/w_728,c_limit/0NE89Nzfk20)

> [!summary] 一言で
> Microsoft の Nadella CEO が、コード生成が安くなった今は検証が難しいと語り、同社が大半のソフトウェアエンジニアに初めて希望退職の機会を出したことも番組紹介で触れられた。

- 「批評するモデル」でも、失敗するテストを消して通すようにゴールをごまかす例があり、検証の決定的な解は出ていない。エージェントは「内部の脅威」として別の検証が要るとも述べた。
- 新卒・ジュニアの採用鈍化は、組織再編中の一時的なものと説明。CMU と組んだ「PRAISE」では、若手と経験者（看護の方式を借りた preceptor）を組ませ、AI 活用・判断・システム思考を教える。
- 希望退職は 12 月まで受け付け、番組紹介では背景に再編・新しい AI 職種（FDE など）・行き詰まりを感じる人の存在が挙げられた。IDE は Claude Code の登場から約 6 か月で影が薄れ、GitHub Copilot が遅れたとも認めた。

> [!tip] So what
> 「コードを書く側から検証する側へ」という Q1 の見立てに沿う発言だが、発言者は雇う側のトップで、番組紹介の範囲の要約。希望退職の理由づけは Microsoft 側の説明であり、数字はまだ出ていない。
