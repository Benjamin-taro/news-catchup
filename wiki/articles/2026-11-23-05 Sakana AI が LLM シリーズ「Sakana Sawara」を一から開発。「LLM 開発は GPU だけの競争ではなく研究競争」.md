# Sakana AI が LLM シリーズ「Sakana Sawara」を一から開発。「LLM 開発は GPU だけの競争ではなく研究競争」

> [!summary] 一言で
> Sakana AI のチーフサイエンティスト秋葉拓哉氏が、RSI Lab で一から作る新しい LLM シリーズ Sakana Sawara を紹介し、研究力の競争だと説明した（X の投稿より）。

- 投稿は、Sawara を RSI Lab で一から作っている LLM シリーズと紹介している。
- 秋葉氏は、LLM 開発は GPU の数だけでなく研究の力が問われる競争だと説明している。
- 時期やモデルの規模はこの投稿から読み取れない。検索で見つけた二次報道では、小型版を 2027 年春とする情報や規模の食い違いがあり、公式の確定情報ではない。

> [!tip] So what
> 日本発の一から作る基盤モデルが動き出した、という位置づけ。性能や公開時期の数字がまだ出ていないので、実力の判断は後続の発表待ち。
