# 個人開発の 3D CAD「SolidCraft」、公開から約 5 週で 150 万 DL。1 日 160〜250 件の PR を AI で回す

![](https://fabscene.com/wp-content/uploads/2026/11/image-113.webp)

> [!summary] 一言で
> 農業系の家業で AI・自動化を担当する米国の開発者が、AI を使ってオープンソースの 3D CAD を作り、約 5 週で GitHub から約 150 万回ダウンロードされた。

- Brennen Herbruck 氏が 10/7 に最初のコミット、10/9 に v0.1.0 を公開。11/12 の v0.41.0 までに正式版を 58 回リリースし、11/13 時点でスターは約 1 万 6000、main への取り込み変更は 5140 件。
- 11/10〜12 は 1 日あたり約 160〜250 件の PR をマージ。コーディング・デバッグ・テスト・レビューに Claude と OpenAI のツール、PR の自動レビューに CodeRabbit、CI の高速化に Blacksmith を使い、AI エージェントが CAD を直接操作できる MCP サーバーも備える。
- 11/11 にはジオメトリのカーネルを Truck から SolidCore に差し替えた（フィレットなどの処理に限界があったため）。ダウンロード数は GitHub 配布分のみの数字。

> [!tip] So what
> 専任の開発チームなしで、数週間で大きな OSS が回っている実例。レビューや CI まで AI に任せる自由度は、情報管理の厳しい業務側ではまだ取りにくいはずで、個人と業務の差を考える材料になる（記事は業務との比較には触れていない）。
