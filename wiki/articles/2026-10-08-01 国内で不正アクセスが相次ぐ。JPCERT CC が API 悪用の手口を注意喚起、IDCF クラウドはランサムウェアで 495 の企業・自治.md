# 国内で不正アクセスが相次ぐ。JPCERT/CC が API 悪用の手口を注意喚起、IDCF クラウドはランサムウェアで 495 の企業・自治体に影響

![](https://www.jpcert.or.jp/common/image/ogp_image.jpg)

> [!summary] 一言で
> JPCERT/CC が 10 月 8 日に大量漏えいにつながる攻撃への注意喚起を出し、同じ頃 IDC フロンティアのクラウドがランサムウェアで止まった。

- JPCERT/CC（AT-2026-0030）は、公開アプリの解析で API のエンドポイントやキーを特定し、内部 API でユーザー権限の変更や不正アカウント作成を行う手口や、Metabase の脆弱性（CVE-2026-72898）の悪用を挙げた。BI ツールや従業員向け管理システムなど、管理側のシステムも狙われている。
- IDCF クラウドは 10 月 7 日 3 時 40 分ごろに東日本第 1 リージョンで障害が発生し、20 時 18 分の第 2 報でランサムウェア攻撃と判明した。契約先 495 の企業・自治体が影響を受け、日水物流は 17 拠点の入出荷が停止、シックス・アパートは 31 台が影響を受けた。
- 復旧は難航しており、UDトークなどは早期のデータ復元は難しいと連絡を受けたという。個人情報の流出は確認中で、はてブでは「免許証画像まで流出する時代にエンジニアは何をすべきか」という Qiita 記事や情報漏洩の Tier 表も話題になっている。

> [!tip] So what
> 個別の事故というより、API と管理系システムを狙う攻撃と、クラウド基盤 1 社の停止が多数の組織に波及する構図が同時に見えた日。委託先やクラウド事業者の単一障害点をどう見るかが、現場の課題になる。侵入経路は調査中で、2 つの件の関係は示されていない。
