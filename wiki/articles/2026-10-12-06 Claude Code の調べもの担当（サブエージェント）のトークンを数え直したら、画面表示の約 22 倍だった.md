# Claude Code の調べもの担当（サブエージェント）のトークンを数え直したら、画面表示の約 22 倍だった

> [!summary] 一言で
> Claude Code のサブエージェント 1 体の消費を記録から数え直すと、会話に表示された数字の約 22 倍だったと、Zenn の記事が報告した。

- 表示は 157,630 トークン、記録ファイルから数え直すと 3,514,672 トークン。計測日は 2026-08-30 と 09-21。
- 差のほとんどはキャッシュ読みで、会話の表示には含まれていない。内訳の詳しい数字は有料の note 側にあり、公開ページには無い。
- 結論は、消費を減らしたいなら書く量より往復の回数を減らすほうが効く、というもの。

> [!tip] So what
> 表示される数字と実際の消費が違うなら、サブエージェントを多用した運用の見積もりも変わる。使用量の把握は、画面の数字ではなくログから行うのが確実。
