# DeepSeek V4.1 Flash 1017 が MIT ライセンスで公開。約 763B パラメータ、DeepSWE 77.0% と自社発表

![](https://cdn-thumbnails.huggingface.co/social-thumbnails/models/deepseek-ai/DeepSeek-V4.1-Flash-1017.png)

> [!summary] 一言で
> DeepSeek が「V4.1 Flash」の小規模更新版を Hugging Face で公開し、コーディングやエージェント系の指標が前版から上がったと説明している。

- モデルカードによると約 763B パラメータ、MIT ライセンス、コンテキスト 1M トークン。DeepSWE v1.1 は 74.2 → 77.0、Terminal-Bench 4.0 は 31.2 → 42.3、HLE（ツールなし）は 36.8 → 42.6。出力を短くして実行時間とコストを下げたと説明している。
- 比較表では Opus 5 が HLE 56.3、Terminal-Bench 4.0 で 51.8 と上回る項目が多い。Terminal-Bench は Claude Code のハーネスで測っている。価格は記載がなく、推論プロバイダーにはまだ展開されていない。
- X では「GPT-6 Astra や Claude Opus 5.5 を上回りコストは桁違い」という投稿が広まっているが、モデルカードの比較対象とは異なり、数字の出所は確認できていない。

> [!tip] So what
> オープンウェイトが上位モデルとの差をコストで詰めてくる構図は続くが、数字はすべて DeepSeek 自身の測定で、第三者の再現はまだ見当たらない。コスト優位の主張は価格の公表待ち。
