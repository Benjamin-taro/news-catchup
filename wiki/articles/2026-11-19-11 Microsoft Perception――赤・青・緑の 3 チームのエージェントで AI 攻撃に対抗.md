# Microsoft Perception――赤・青・緑の 3 チームのエージェントで AI 攻撃に対抗

![](https://www.publickey1.jp/2026/HXWPdJiXoAAF46K.png)

> [!summary] 一言で
> Microsoft が、AI による攻撃に AI エージェントで対抗するサービス「Microsoft Perception」の提供を始めた。

- レッドチーム（攻撃前の脆弱性発見）、ブルーチーム（検知・調査・対応）、グリーンチーム（修復・リスク低減）の 3 つのエージェントが、「プレイブック」に従って自律的に動く。
- 重要な判断が必要な場面では人間が判断する。グリーンチームの手順は Microsoft の基盤に加え、AWS と Google Cloud も対象。

> [!tip] So what
> 防御側も人の速度では間に合わないという前提が、製品の設計に入っている。「人が判断する場面」をどこに置くかが分かる例。
