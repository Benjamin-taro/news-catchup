# 3人それぞれの Claude Code を Slack でつないで ISUCON2026 に参加、207,039点

> [!summary] 一言で
> 3人が自分の PC で動かした Claude Code 同士を Slack 経由で連携させ、ISUCON2026 でスコア 207,039 点を出した記録。

- エージェント同士は会話履歴を共有せず、Slack 上の「CLAIM」「DEPLOY_REQ」「BENCH_DONE」といった1行の書式と、`GOAL.md`、デプロイを1人に絞る `make lock` で調整した。
- 14時台後半から人間はコードもコマンドも書かず、目標と方針を伝える役に回った。16時〜17時56分に失敗を含め約40回ベンチマークを実行し、推定費用は約944ドル（約25億トークン）。
- 「1位以外は最下位と同じ」と指示すると大きな変更案を試すようになった一方、手近な改善の積み重ねでは上位（約60万点）に届かなかった。差は道具・手順・問題への知識で生まれると振り返っている。

> [!tip] So what
> 人間が目標と問いの立て方に回り、複数のエージェントを並べて回すという働き方が実例で出てきた。ただしエージェントだけでは上位に届かなかったという点は、技術の知識が残る側の材料にもなる。
