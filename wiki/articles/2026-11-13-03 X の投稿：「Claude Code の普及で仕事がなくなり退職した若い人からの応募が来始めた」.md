# X の投稿：「Claude Code の普及で仕事がなくなり退職した若い人からの応募が来始めた」

![](https://lh3.googleusercontent.com/J6_coFbogxhRI9iM864NL_liGXvsQp2AupsKei7z0cNNfDvGUmWUy20nuUhkREQyrpY4bEeIBuc=s0-w300-rw)

> [!summary] 一言で
> ある採用側の投稿が、Claude Code の急速な普及で仕事を失い退職した若手からの応募が来始めたと述べている（投稿のみで、裏付けとなる数字はない）。

- 投稿の主張は「Claude Code の急激な普及で仕事がなくなり、退職せざるを得なくなったという理由の応募が来始めている」。「ついにきた」と受け止めている。
- 投稿者名・会社名・応募の件数や職種は、取得できた本文には書かれていない。
- 同じ日の他の投稿には、動画編集のフリーランスが AI で打ち手が増えたと語るものもあり、受け止めは割れている。

> [!tip] So what
> 採用の現場で「AI が理由の離職者」が見え始めたという 1 件の逸話。職種の消滅か人数の調整かは、これだけでは判断できない（Q3 の見立てを支持する方向の材料だが、数字が必要）。
