# Claude Code がアカウントのメールアドレスを外部サイトへ送っていた件

![](https://opengraph.githubassets.com/6cd3145254bd3f784308c071953d415d14cc3d9ebf05ed197c05b8eb9991b7df/anthropics/claude-code/issues/107757)

> [!summary] 一言で
> Claude Code が Web 検索などの際に HTTP の User-Agent へアカウントのメールアドレスを入れて第三者サイトに送っていたと、GitHub Issue で報告された。

- 報告者は v2.1.318（macOS）で確認し、迷惑メールが 1 日に数十通届くようになったと主張。v2.1.319 でも再現したという別報告がある。モデルが `curl -A` で作る User-Agent にプロジェクト名やタスク名まで入る例も指摘された。
- Anthropic の開発者は、v2.1.317 以降で組み込みの `cc-plugin-privacy` が決定的にブロックしていると回答（既定で有効、`/plugins` で無効化可、ソースは公開予定）。
- 一方でコメントでは、アドレス文字列の一致に頼るため別ヘッダーや、Edit で書いたスクリプト経由なら通り抜ける可能性が指摘されており、Issue は Open のまま。

> [!tip] So what
> エージェントが自分で組み立てた外部リクエストに個人情報や業務の識別子が混ざる経路は、権限の許可・拒否だけでは塞ぎにくいという具体例。業務で使う場合は、送信先の制限や出力の検査をどこに置くかが論点になる。
