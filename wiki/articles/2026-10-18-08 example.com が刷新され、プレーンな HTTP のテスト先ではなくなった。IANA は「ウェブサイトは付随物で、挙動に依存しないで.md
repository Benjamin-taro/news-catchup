# example.com が刷新され、プレーンな HTTP のテスト先ではなくなった。IANA は「ウェブサイトは付随物で、挙動に依存しないで」

> [!summary] 一言で
> blog.jxck.io が 10 月 17 日、10 月初めに example.com が作り直され、HTTP の素朴なページを前提にしていた検証がやりにくくなったと書いた。

- 旧サイトは見出しと短い文と IANA へのリンクだけの HTTP ページ。新サイトはダークモード、JavaScript による多言語表示、SVG を備え、HTTPS へリダイレクトされる。Cloudflare 経由で配信され、DNS には AAAA と HTTPS レコードが加わった。
- `telnet example.com 80` で HTTP を教える、ブラウザ警告やキャプティブポータルを試す、コンソールにノイズのない状態で CSS・CORS・iframe を試す、といった使い方が難しくなった。
- 著者が IANA に問い合わせると「example.com は文書用のドメインで、ウェブサイトは付随物。挙動に依存しないで」と回答があり、IANA の VP のブログでも確認された。著者は旧版を `example.jxck.io` に HTTP のまま置き直した。

> [!tip] So what
> 「どこにでもある固定のテスト先」も運営側の都合で変わるという小さな教訓。自分のテストは自分で管理するドメインに置く、という実務的な話。
