# OpenAI の GPT-6 と Codex が Google Cloud で提供開始。主要 3 大クラウドすべてで OpenAI のモデルが使える状態に

![](https://media.thenextweb.com/2026/09/openai-gpt-6-sol-luna-key-art.jpg)

> [!summary] 一言で
> Google Cloud が 10/21 に OpenAI の GPT-6 Astra・GPT-6.1 Sol・GPT-6 Luna と Codex の提供を発表した。

- Model Garden でのプライベートプレビューで、まず一部の法人顧客が対象。一般提供は「数週間以内」。Google Cloud Marketplace 経由で買え、既存の Google Cloud の支出コミットメントで払える。プロンプトと出力は顧客のデータ境界内に留まり、学習には使わないと Google は説明。
- Google Cloud は、Anthropic の Claude・自社の Gemini と合わせ、主要な非公開モデル 3 種すべてを出すのは自社だけだと位置づける。Microsoft は引き続き OpenAI の主要クラウドパートナーで、Amazon は 4 月から提供済み。
- 数字：Google Cloud の売上成長率は第 2 四半期に約 82%（CNBC 報道）、Amazon 37%、Microsoft 42%。Anthropic の 2025 年売上の 47% は Amazon・Google のクラウド経由（IPO 目論見書、Reuters 報道）。

> [!tip] So what
> モデルの囲い込みよりクラウド経由の販売網が競争の軸になってきた。数字は報道の引用で、一次の発表（OpenAI・Google のブログ）は未確認。
