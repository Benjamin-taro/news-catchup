# Claude Code 週間まとめ（11/8〜11/14）：Fable 5.2 は入力 $8・出力 $40、sandbox 内の Bash も既定で許可確認へ

![](https://res.cloudinary.com/zenn/image/upload/s--Xds7_qZ9--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:Claude%2520Code%2520%25E9%2580%25B1%25E9%2596%2593%25E3%2583%258B%25E3%2583%25A5%25E3%2583%25BC%25E3%2582%25B9%25EF%25BC%258811%252F8%25E3%2580%259C11%252F14%25EF%25BC%2589%25EF%25BC%259AFable%25205.2%25E3%2583%25BBSheets%25E3%2583%25BBMeetings%25E3%2583%25BB...%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:%25E3%2581%259A%25E3%2582%2593%25E3%2581%25A0%25E3%2582%2582%25E3%2582%2593%25E3%2581%25AE%25E5%25AE%259F%25E9%25A8%2593%25E9%2581%2593%25E5%2585%25B7%25E7%25AE%25B1%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyLzJiNGRhMmQyODEuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)

> [!summary] 一言で
> この 1 週間の Claude / Claude Code の変更を、Fable 5.2・Sheets・Meetings・sandbox の確認動作を中心に整理した Zenn の記事。

- Claude Fable 5.2（11/9）は評価したほぼすべての項目で Opus 5.5 を上回る。単価は Fable 5.1 から約 2 割下がり、100 万トークンあたり入力 $8・出力 $40（Opus 5.5 の 2 倍）。「1 タスクの費用が約半分」は Fable 5.2 の High と Opus 5.5 の Max の比較で、評価は FrontierCode 2.0 の 1 件だけ。既定モデルは Opus 5.5 のまま。
- Claude Code 2.1.325 で、sandbox 内の Bash も既定で通常の許可フローを通るようになった（戻すには `sandbox.autoAllowBashIfSandboxed: true`）。定期タスクや `/loop` は、`allowed-tools` や hooks を持つスキルの実行前に確認が入る。2.1.323 では「今後は聞かない」を選んでも、秘密を含みそうな規則は保存されず、そのセッションだけ有効になる。
- Claude Meetings（ベータ・11/12）で Google Meet の通話に Claude が参加できる。Sheets・Whiteboards（ベータ）と Data も登場。Data のライブ共有は、共有相手がデータ源の権限を持たなくても結果が見える点に注意が要る。

> [!tip] So what
> 無人実行（`-p` や Agent SDK では usage credits の課金が確認なしに行われる）と、許可確認を既定でどこまで挟むかの線引きが、週ごとに動いている。自動化に載せるなら更新のたびに確認が要る。
