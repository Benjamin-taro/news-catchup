# Microsoft、AI が作ったアプリを社内で安全に動かす「Copilot Managed Runtime」を GA

![](https://www.publickey1.jp/2026/copilot-managed-runtime-ga01.png)

> [!summary] 一言で
> Microsoft が Ignite 2026 で、プログラマ以外の社員が AI で作ったアプリを、自社テナント内で安全に実行するマネージド基盤を正式リリースした。

- Microsoft 365 と同じテナント境界内で動き、Entra ID による認証、アクセス制御、ポリシー適用、監査ログを使える。ホスティングとスケーリングは Microsoft が運用する。
- 1,500 種類以上のデータソースへのコネクタ、Microsoft Graph、Work IQ に接続できる。情報部門はアプリ一覧と状態を管理画面で確認できる。
- Copilot Code・Cowork・Studio、GitHub Copilot、VS Code から使え、サードパーティも SDK で対応できる。

> [!tip] So what
> 「業務側にも自由に作らせる。ただし隔離・権限・監査の枠の中で」という形が製品として出てきた。個人開発の自由度と業務の統制の差が、枠の設計で埋まるのかを見る材料。
