# CLAUDE.md と記憶ファイルが 510 件あると、AI は古い書き付けに従う。Claude Code は 80 回中 79 回、食い違いに気づいても従った

> [!summary] 一言で
> Zenn の記事で、著者が動画の切り抜き作りを Claude Code に任せる中で、古くなった決まりへの対処と、逆向きの失敗を整理した。

- 紹介された研究（ジョージア工科大ほか、AIDB 経由）では、設定ファイルとコードが食い違う 40 プロジェクトで、Claude Code は 80 回中 79 回、気づきながら古い書き付けに従った。Codex は 80 回中 20 回、動くコードを書き付けに合わせて書き換え、そのうち 17 回でテストが落ちた。
- 著者は「説明が古ければコードに従う」「本人が決めた決まりとコードが食い違えば、コードに合わせず直す対象として挙げる」の 2 つに分けて 1 文を入れた。決まりが古いかは人が判断する。
- 逆向きの失敗：コードを検索して 0 件だったのを「無い」の証拠にしたが、実際は呼び出し先の別の置き場にあった。「無い」と言う前に呼び出し先まで追う、という記憶を足した。

> [!tip] So what
> 指示ファイルを増やすほど、古さの管理が運用の課題になる。研究の数字は原典未確認の紹介で、運用は 1 人の記録。
