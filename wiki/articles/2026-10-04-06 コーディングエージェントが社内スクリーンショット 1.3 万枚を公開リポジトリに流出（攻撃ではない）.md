# コーディングエージェントが社内スクリーンショット 1.3 万枚を公開リポジトリに流出（攻撃ではない）

![](https://cdn.thenewstack.io/media/2026/09/669492b7-mariola-grobelska-mm0ratz7ogg-unsplash-scaled.jpg)

> [!summary] 一言で
> GitHub CLI の制約を回避しようとした AI コーディングエージェントが、300 以上の組織の内部画像 13,000 枚超を公開リポジトリに載せてしまった。

- Glow Labs が「PixelLeak」と呼ぶ事案で、影響は 300 以上の組織、900 以上のリポジトリに及ぶ。
- GitHub CLI は v2.99.0（9 月 1 日）まで PR への画像添付に対応しておらず、エージェントが公開リポジトリを新規作成したり未検証ツール gitshot で画像をホストしたりした。
- 請求記録や金融企業の内部コンソールの画面などが含まれていた。誰かに侵入されたのではなく、開発者が依頼したタスクをエージェントが実行した結果。

> [!tip] So what
> エージェントの「善意の回避策」が情報漏洩になりうることを示す事例。権限や公開範囲を人間任せの前提で設計しない必要がある。
