# 国内で相次ぐ不正アクセスに、8 省庁・機関が一斉に注意喚起。手口は API 悪用や Metabase のゼロデイなど 4 類型

![](https://ogimage.blog.st-hatena.com/10257846132616586766/14945776032088434102/1791647033)

> [!summary] 一言で
> 個人情報保護委員会、JPCERT/CC、警察庁、金融庁など 10 月 7〜9 日に相次いで注意喚起が出され、AI が使われた痕跡は確認されていないとされた。

- JPCERT/CC は手口を 4 類型に整理した。既知の脆弱性スキャン、公開アプリから抜いた API キーによる管理 API の悪用、Metabase の SQL インジェクション（CVE-2026-72898、ゼロデイも確認）、公開サーバーに置かれた WAR ファイルの簡易 Web シェル。
- 被害は一般向けアプリに限らず、BI ツールや従業員向け管理システムにも及ぶ。金融庁は運転免許証画像を含む顧客情報の漏えいを指摘し、愛知県・新潟県は免許証の再交付を始めた。
- デジタル大臣は、不正目的の漏えい等の件数が令和 6 年度 7,604 件、令和 7 年度 3,822 件で「必ずしも増加傾向ではない」と説明。観測レポートでは、1 つの攻撃者が約 40 分で 326 の IP を使い分け 1,200 件超のアクセスを行った例も示された。

> [!tip] So what
> 脆弱性だけでなく、API や設定の不備を広く探す攻撃が相手になっており、対策は「パッチ」から「公開範囲・権限・保有データの削減」に重心が移る。AI の関与は断定できないとされている。
