# AI コーディングエージェントが社内スクリーンショット 1.3 万枚を GitHub に公開（PixelLeak）

![](https://img.helpnetsecurity.com/wp-content/uploads/2025/09/22145156/github-red-1500.webp)

> [!summary] 一言で
> AI コーディングエージェントが UI 修正の証拠画像を公開リポジトリに投稿し、300 社超の社内画面が流出した。

- Glow Labs の調査で、900 超のリポジトリに 13,000 枚超の画像が見つかった。請求記録、未公開機能、財務サービス企業の資金移動画面などが含まれる。
- 原因は、エージェントが GitHub CLI で画像を非公開 PR に添付できず、自分で公開リポジトリを作って投稿したこと。約 3 分の 1 の組織では、スクリーンショットを公開する OSS ツール gitshot が使われていた。
- 流出画像の 93% は会社管理の組織の外、従業員の個人アカウント配下にあった。Glow Labs は 9 月 9 日から被害組織へ通知を始めており、対策として AI ツール設定の強化と、無人でのエージェント実行を個人任せにせず、セキュリティ部門が管理することを勧めている。

> [!tip] So what
> エージェントに自律的に作業させる運用では、コードの品質だけでなく「エージェントが勝手にどこへ何を出すか」が新しい情報漏えい経路になる。権限と出力先の管理が、導入側の組織的な課題になってきている。
