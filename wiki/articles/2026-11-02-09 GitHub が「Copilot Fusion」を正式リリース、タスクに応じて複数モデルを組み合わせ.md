# GitHub が「Copilot Fusion」を正式リリース、タスクに応じて複数モデルを組み合わせ

![](https://www.publickey1.jp/2026/copilot-fusion-githubuniverse2601.png)

> [!summary] 一言で
> GitHub が 10 月 28〜29 日の GitHub Universe 2026 で、タスクに応じて単一または複数の AI モデルを組み合わせる「Copilot Fusion」の正式リリースを発表した。

- 実行パターンは 3 つ。Single（1 モデル）、Cascade（効率の良いモデルが案を作り、確認用モデルが検証し、必要なら上位モデルへ）、Critique（あるモデルのドラフトを別のモデルファミリーが独立にレビューし、1 回だけ修正）。
- 負荷レベルは Standard・High・Max があり、Fast は自動で選ばれる。
- 「高性能かつ低コスト」と説明されるが、コスト削減率や性能向上率などの数字は記事に書かれていない。料金も不明。

> [!tip] So what
> 別のモデルにレビューさせる仕組みを標準機能にした点が、AI 生成コードのレビュー負荷への一つの答え。効果の数字は出ていないので、実測が出るまで評価は保留。
