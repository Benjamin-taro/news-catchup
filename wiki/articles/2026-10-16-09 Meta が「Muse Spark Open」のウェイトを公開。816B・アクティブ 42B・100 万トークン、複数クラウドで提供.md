# Meta が「Muse Spark Open」のウェイトを公開。816B・アクティブ 42B・100 万トークン、複数クラウドで提供

![](https://research.meta.ai/articles/muse-spark-open/social/muse-spark-1-2-open-weights-social-v2.webp)

> [!summary] 一言で
> Meta が、自社で「米国で最も高性能なオープンウェイトモデル」と呼ぶ Muse Spark Open のウェイトを公開した。

- 総パラメータ 816B、アクティブ 42B、コンテキスト 100 万トークン。マルチモーダルで、コーディングやエージェント作業向け。Muse Model License の下で、商用には限定的な条件がある。
- 配布先は Hugging Face、Amazon SageMaker AI、Google Cloud Model Garden、Microsoft Foundry など。Baseten、Fireworks、Groq、OpenRouter、Together などの API でも使える。Apple M5 Ultra の Mac Studio 2 台で動かせるとも説明する。
- ベンチマークの点数は取得できた本文になく、数字は Meta 自身の SGLang の最適化（NVIDIA・AMD で 1.03〜3.95 倍）のみ。安全性の評価レポートは「近日公開」。

> [!tip] So what
> オープンウェイトの競争が、巨大モデルを主要クラウドで同時に配る段階に入っている。ただし性能は自社発表で、第三者の検証はまだ。
