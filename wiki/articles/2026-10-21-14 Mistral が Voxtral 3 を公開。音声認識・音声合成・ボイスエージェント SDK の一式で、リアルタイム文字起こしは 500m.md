# Mistral が Voxtral 3 を公開。音声認識・音声合成・ボイスエージェント SDK の一式で、リアルタイム文字起こしは 500ms 未満

![](https://mistral.ai/cms-media/api/media/file/hero-blog-voxtral.png)

> [!summary] 一言で
> Mistral AI が、音声認識（Small / Mini）、リアルタイム認識、音声合成（Speech 3）と、LiveKit ベースのボイスエージェント SDK をまとめて出した。

- 文字起こしは 1 分あたり 0.0035〜0.008 ドル、音声合成は 100 万文字 13 ドル、ボイスエージェント API は Mistral Small 4 を使うと 1 分 0.04 ドル。EU のホスティング API か自社環境へのデプロイが選べる。
- Mistral は FLEURS（45 言語）で Whisper・Scribe v2・Gemini 3.5 Transcribe を上回ると主張。リアルタイム版は 35 以上の言語で 500ms 未満の遅延とする。ライセンスは記事中に記載がなく、すべて自社評価。

> [!tip] So what
> 音声エージェントの部品を価格つきで一式そろえ、EU ホスティングを売りにした位置づけ。性能は自社発表で第三者の検証はまだない。
