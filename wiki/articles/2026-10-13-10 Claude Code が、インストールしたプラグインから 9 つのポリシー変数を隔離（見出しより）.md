# Claude Code が、インストールしたプラグインから 9 つのポリシー変数を隔離（見出しより）

![](https://lh3.googleusercontent.com/J6_coFbogxhRI9iM864NL_liGXvsQp2AupsKei7z0cNNfDvGUmWUy20nuUhkREQyrpY4bEeIBuc=s0-w300-rw)

> [!summary] 一言で
> MIXED Reality News が、Claude Code が管理者の設定のうち 9 つのポリシー変数をプラグインから書き換えられないようにしたと報じた（見出しより）。

- 本文は取得できなかった。「9 つ」の中身は確認できていない。
- 公式ドキュメントによれば、プラグインの導入と許可は管理設定で決まり、利用者は上書きできない。マーケットプレイスの制限は `strictKnownMarketplaces` など。管理設定は複数の配信元のうち最初に値を返したものが適用される（既定）。
- どの変数が対象かは、公式の「control matrix」を確認する必要がある。

> [!tip] So what
> プラグインが管理者の統制を迂回できない方向に Claude Code が寄っている。企業で使うときの権限管理の足場として、変更点の一次情報を読む価値がある。（見出しより）
