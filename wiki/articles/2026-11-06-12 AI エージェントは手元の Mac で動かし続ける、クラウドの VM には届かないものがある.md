# AI エージェントは手元の Mac で動かし続ける、クラウドの VM には届かないものがある

![](https://res.cloudinary.com/zenn/image/upload/s--hZcRG3B3--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:AI%25E3%2582%25A8%25E3%2583%25BC%25E3%2582%25B8%25E3%2582%25A7%25E3%2583%25B3%25E3%2583%2588%25E3%2582%2592%25E6%2589%258B%25E5%2585%2583%25E3%2581%25AEMac%25E3%2581%25A7%25E5%258B%2595%25E3%2581%258B%25E3%2581%2597%25E7%25B6%259A%25E3%2581%2591%25E3%2582%258B%25E7%2590%2586%25E7%2594%25B1%2520%25E2%2580%2595%2520%25E3%2582%25AF%25E3%2583%25A9%25E3%2582%25A6%25E3%2583%2589%25E3%2581%25AEVM%25E3%2581%25AB%25E5%25B1%258A%25E3%2581%258B%25E3%2581%25AA%25E3%2581%2584%25E3%2582%2582%25E3%2581%25AE%25E3%2581%25A8%25E3%2580%2581%25E6%258A%2580%25E8%25A1%2593%25E3%2581%25AE%25E5%259C%259F%25E5%259C%25B0%25E5%258B%2598%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:%25E3%2581%25BF%25E3%2582%2584%25E3%2581%25A3%25E3%2581%25A1%2520Toshimitsu%2520Mi...%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyLzJlOGEzNzVmY2QuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)

> [!summary] 一言で
> Claude Code や Codex を手元の Mac で常時動かす理由を、クラウドの VM との違いから整理した個人の運用記事。

- クラウドのエージェントは別の VM で動くため、手元のファイル・ブラウザのログイン・普段のアプリに直接触れず、渡せるのは GitHub などを通じて届けたものだけ。スマホのアプリは指示と確認の窓口で、作業は手元の PC が行う。
- 手元で動かす場合はスリープやネットワーク切断でリモート操作が止まるため、PC の役割が「人が使う道具」から「AI が働く場所」に変わる。自宅とオフィスの Mac を開けたままにして外出先からスマホで指示を出す運用が例に挙がる。
- ローカルかクラウドかは「その仕事に必要なものがどのマシンにあるか」で選ぶ、という基準を比較表で示す。VM の仕組みを掘り下げると、AI への指示や判断の質が上がるとも述べる。

> [!tip] So what
> 個人の運用では、手元の環境をそのまま使える自由度が選ばれる理由になっている。業務ではその同じ「手元に届く」が制限の対象になりやすく、Q7（個人と業務の分かれ方）の個人側の例。
