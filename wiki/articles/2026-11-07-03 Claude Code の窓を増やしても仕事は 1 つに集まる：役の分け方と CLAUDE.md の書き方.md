# Claude Code の窓を増やしても仕事は 1 つに集まる：役の分け方と CLAUDE.md の書き方

![](https://res.cloudinary.com/zenn/image/upload/s--nx_Dv7bp--/c_fit%2Cg_north_west%2Cl_text:notosansjp-medium.otf_55:Claude%2520Code%2520%25E3%2581%25AE%25E7%25AA%2593%25E3%2582%2592%25E5%25A2%2597%25E3%2582%2584%25E3%2581%2597%25E3%2581%25A6%25E3%2582%2582%25E3%2580%2581%25E4%25BB%2595%25E4%25BA%258B%25E3%2581%25AF1%25E3%2581%25A4%25E3%2581%25AE%25E7%25AA%2593%25E3%2581%25AB%25E9%259B%2586%25E3%2581%25BE%25E3%2582%258B%25E3%2580%2582%25E5%25BD%25B9%25E3%2581%25AE%25E5%2588%2586%25E3%2581%2591%25E6%2596%25B9%25E3%2581%25A8%2520CLAUDE.md%2520%25E3%2581%25AE%25E6%259B%25B8%25E3%2581%258D%25E6%2596%25B9%2Cw_1010%2Cx_90%2Cy_100/g_south_west%2Cl_text:notosansjp-medium.otf_37:Ciel%2Cx_203%2Cy_121/g_south_west%2Ch_90%2Cl_fetch:aHR0cHM6Ly9zdGF0aWMuemVubi5zdHVkaW8vdXNlci11cGxvYWQvYXZhdGFyLzAyZGJiOGEwYzEuanBlZw==%2Cr_max%2Cw_90%2Cx_87%2Cy_95/v1627283836/default/og-base-w1200-v2.png?_a=BACMTiAE)

> [!summary] 一言で
> 複数の Claude Code を並べて使う筆者が、役割を文書に書かないと「話が早い窓」に仕事が集まると気づき、窓ごとの CLAUDE.md の頭に書く 4 項目を整理した。

- 記事を書く窓の CLAUDE.md が 71KB に膨らんでいたが、役割を分けて渡し先を決めたところ、約 11 分で約 19KB に減った。
- 公開ボタンを押す役は 7 日間で 4 回変わった。伝言だけで変えると、受け取る窓の CLAUDE.md が古いまま残り食い違いが出たため、役割を変えるときは伝言と該当行の両方を直す。作業フォルダを窓ごとに分けると持ち主がフォルダで分かる。
- 書く 4 項目は「持つ物」「渡した物（渡し先）」「押す役（公開・送信など）」「触らない所」。2 つの窓の「持つ物」を並べて重なりを見つける。

> [!tip] So what
> 並列運用では、速さより「誰が最後の確認と公開を担うか」の線引きが問題になる、という個人の運用記録。再現できる書式がある一方、1 人の運用の数字で一般化はできない。
