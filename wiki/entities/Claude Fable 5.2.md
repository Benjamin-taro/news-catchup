# Claude Fable 5.2

## 概要
Anthropic が 11/9 に公開したモデル（全ユーザー向け。審査を通った組織向けの Mythos 5.2 と同じ基盤）。価格は入力 100 万トークンあたり $8・出力 $40で、Claude Code や Google Cloud などで使える。
公表値と個人の実測がずれる点（単価、キャッシュ書込、速度）まで含めて、モデル競争の読み方を考える材料になる。
