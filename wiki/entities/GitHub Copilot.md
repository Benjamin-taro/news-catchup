# GitHub Copilot

## 概要
GitHub の AI コーディング支援。共通ランタイム（本番の TypeScript 約 43 万行）を、AI エージェント群と開発者 1 人で数か月かけて Rust に移植した（自己申告）。
書く作業をエージェントに寄せ人は設計・契約・検証に回る実例として、Q1 の材料になる。
