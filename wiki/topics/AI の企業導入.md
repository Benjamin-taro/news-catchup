# AI の企業導入
**関係する問い**：[[Q4]]

## 現状のまとめ
- 大手行の AI が、ベンダーの FDE と基盤に寄せて進む例が出た。[[Northern Trust]] は [[Microsoft]] の FDE チームと Azure・Foundry 上で顧客オンボーディングのエージェントを作り、データ準備を 83% 減、期間を 2 週間半から 3 日にした（アナリストが承認する形、数字は発表側。[[2026-11-12-01 Northern Trust が Microsoft の FDE と顧客オンボーディングのエージェントを構築：データ準備 83% 減、2 週|Northern Trust]]）。Wells Fargo の富裕層部門は、200 超のツールを束ねる Advisor Gateway の上にアドバイザー向け「AI Teammate」を載せ、数か月で数十万回の利用があったが、自社開発かベンダー製かは記事から判断できない（Digest 11/11）。前週までは、Revolut の自社ホスト GLM（推論費用約 90% 減）、SMFG の 3 年 1,000 億円・100 件超、八十二長野の行専用基盤など、自前に寄る例が並んでいた。
- 業務側に入れるには、文書と設定の整備が要る。Claude Code を社内に入れるための稟議の雛形、情シス向けの回答表、3 段階の managed-settings.json、確認スクリプトをまとめた本が Zenn に出た（[[2026-11-10-11 Claude Code を社内に入れるための「申請書・回答表・管理設定」一式が Zenn の有料本に|導入キット]]、設定の中身は有料部分で未確認）。ビズリーチは業務担当者が書いたスキルを GKE 上の隔離環境で Web から動かす基盤を作り、Ubie は全社の仕事をエージェントで回す内製基盤を公開した（Digest 11/12。成果の数字なし）。
- 外から来るエージェントへの対応は分かれ続けている。[[United Airlines]] は未承認の第三者 AI エージェントによる航空券の予約を禁止し、Southwest は ChatGPT から在庫を見せる（[[2026-11-12-04 United Airlines が、外部の AI エージェントによる航空券の予約を禁止|United]]）。前週までは、銀行が内側の AI を広げ外から来るエージェントは閉じる形でそろっていた。
- 法務・小売など他業種でも導入の形が出た。英国の Addleshaw Goddard は Harvey を、Fieldfisher は 6 週間のパイロットを経て Legora を事務所全体の基盤に選び、併用はしない（[[2026-11-10-09 大手法律事務所が AI 基盤を選ぶ：Addleshaw Goddard は Harvey、Fieldfisher は Legora|法律事務所]]）。ファミリーマートは飲料補充のフィジカル AI ロボットを 2027 年 1 月から全国に本格導入する（台数・費用は未確認。[[2026-11-12-12 ファミリーマートが、飲料を自動で補充するフィジカル AI ロボットを 2027 年 1 月から全国の店舗へ本格導入|ファミマ]]）。
- 効果の読み方は割れたまま。Artificial Lawyer は Big Law の AI 発表が顧客への数字（費用・納期・質・リスク）を示していないと問う（Digest 11/13、見立ての段階）。前週までは Apollo の「S&P 493 では利益が見えない」、Microsoft の早期退職打診（約 27%）、Barclays・Amex の削減（AI の内訳なし）が並んでいた。

## 論点と立場
- **自前か購入か**：Revolut・SMFG・八十二長野・PNC は自前に寄るが、Northern Trust はベンダーの FDE と共同構築、法律事務所は外部基盤（Harvey・Legora）に寄せて差が出る部分だけ自前で持つ。いずれも 1 社の自己申告か発表で、同じ軸では比べられない。
- **外部エージェントを入れるか閉じるか**：United・銀行・Delta・Amazon は閉じ、Southwest・Target・参照専用の連携は開く。共通の論点は、認証情報の共有とエージェントが動かした取引の責任。
- **導入の単位は道具か、役割か**：Sakana AI は AI を役割として銀行に組み込む助言を紹介。ビズリーチは業務担当者のスキルを製品化する単位にする。Northern Trust は「エージェント + 人の承認」を単位にする。
- **効果は見えているか**：Northern Trust の 83% 減は自己申告で、FDE の費用は含まれない。Artificial Lawyer は顧客側の数字を求める。JPMorgan は決算にまだ見えないとする。
- **統制は誰が持つか**：中央に集める（Wells Fargo）、業務システムが握る（Workday）、導入文書と管理設定で枠をつくる（導入キット）、行内の AI を規程で一覧管理する（八十二長野）。
