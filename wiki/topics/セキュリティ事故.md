## 現状のまとめ
- 先週のタイムズカーなど個別の事故から、今週は「国内で連日続く」状況そのものが論点になった。楽天会員 1.01 億件の販売主張（未確認）、[[GMO]] の 94 万件流出などが重なり、デジタル相が注意を呼びかけた（[[2026-10-06-03 国内で不正アクセスが連日続く。楽天会員 1.01 億件の販売主張、GMO の 94 万件流出、Qilin 幹部の拘束|連日の報道]]）。
- 原因の見立てが具体化した。JPCERT/CC は API キーの悪用や Metabase の脆弱性（CVE-2026-72898）などを挙げ（[[2026-10-08-01 国内で不正アクセスが相次ぐ。JPCERT CC が API 悪用の手口を注意喚起、IDCF クラウドはランサムウェアで 495 の企業・自治|JPCERT/CC]]）、8 省庁・機関が一斉に注意喚起した。AI が使われた痕跡は確認されていない（[[2026-10-11-02 国内で相次ぐ不正アクセスに、8 省庁・機関が一斉に注意喚起。手口は API 悪用や Metabase のゼロデイなど 4 類型|注意喚起]]）。
- 基盤の停止が波及した。[[IDCフロンティア]]のクラウドがランサムウェアで止まり 495 の企業・自治体に影響、復旧は難航した（[[2026-10-10-01 IDCF クラウドにランサムウェア攻撃、495 の企業・自治体に影響。東日本リージョンの復旧が難航|IDCF]]）。[[Yandex]] ではドローン攻撃による火災で ru-central1-b が 3 日たっても復旧していない（[[2026-10-11-05 Yandex Cloud の ru-central1-b がドローン攻撃による火災で停止、3 日たっても復旧せず|Yandex Cloud]]）。
- 海外では、[[Lee Jae Myung|李在明]]大統領が韓国の銀行の漏えいで政府横断の調査を命じ、AI ツールの関与も調べる（[[2026-10-06-01 韓国大統領が金融機関の情報漏えいで全面調査を指示。AI ツールが攻撃に使われた疑いも調べる|韓国]]）。デンマークの国民登録簿からは約 880 万人分が流出した（[[2026-10-11-01 デンマークの国民登録簿（CPR）から約 880 万人分が流出。「123456」のパスワードの口座が悪用される|CPR]]）。

## 論点と立場
- **増えているのか**：デジタル大臣は、不正目的の漏えい等の件数は令和 6 年度 7,604 件、令和 7 年度 3,822 件で「必ずしも増加傾向ではない」と説明する。一方、短期間に集中して報じられていること自体が社会的な問題になっている。
- **対策の重心**：パッチだけでなく、公開範囲・権限・保有データの削減へ移るという整理（piyolog 経由）。金融庁は免許証画像による本人確認の見直しを求めている。
- **AI は攻撃に使われたか**：韓国では AI ツール「ARTEX」が取り沙汰されているが、ツールと被害の因果は確定していない（[[2026-10-09-02 韓国の金融機関攻撃に使われたとされる中国製 AI ツール「ARTEX」、公開停止と Reuters|ARTEX]]）。国内の事案では AI の痕跡は確認されていない。
- **単一障害点**：クラウド事業者の管理基盤が狙われると、利用者側のバックアップでは防げない。別事業者・別リージョンへの退避を前提にすべきだという見方は記事内の評価。
