# セキュリティ事故

## 現状のまとめ
- [[タイムズカー]]の約 660 万件の漏えいは、続報でパスワードや連携 ID、退会者・入会途中の人のデータまで含まれると分かり（[[2026-09-29-06 タイムズカーの漏えい、パスワードや連携 ID まで流出（続報のまとめ）|続報]]）、退会者の免許証画像を 7 年保存していた理由と信用情報機関の手続き遅延も報じられた（[[2026-09-30-02 タイムズカーの漏えい、「7 年保存」の理由と、信用情報機関の手続き遅延|7 年保存]]）。
- 金融・物流でも [[第一生命]]（人事システム、従業員約 12 万人分）と [[ヤマト運輸]]（後払い決済）の不正アクセスが公表され、周辺システムが狙われている（[[2026-10-02-01 第一生命で従業員12万人分の情報漏えいの可能性、ヤマト運輸も後払い決済に不正アクセス|第一生命・ヤマト]]）。
- AI エージェントが絡む事案が増えた。エージェントが公開リポジトリに内部画像を載せた PixelLeak（[[GitHub]]）、韓国の銀行 6 行への「自律侵入」の報道（根拠は詳しく示されていない）。
- 開発者を狙う手口として、案件を装い [[Git]] の `post-checkout` フックで認証情報を狙う例が出た（[[2026-10-03-07 「案件の依頼」を装い git の post-checkout フックで認証情報を狙う手口|post-checkout]]）。

## 論点と立場
- **データをなぜ持ち続けたか**：パーク24 は、7 年の根拠を法人税法上の保存義務としつつ、免許証画像には法的根拠がなく「なりすまし対策・問い合わせ対応」のためと説明した。「念のため残す」データが被害を最大にしたという見方が出ている。
- **被害の広がり方**：事故後に「CIC・JICC に届け出を」という呼びかけで申し込みが集中し、手続きが遅れた。補償の有無は未定。
- **攻撃か、エージェントの善意か**：PixelLeak は誰かに侵入されたのではなく、開発者が依頼したタスクをエージェントが実行した結果。Glow Labs は AI ツール設定の強化と、無人実行をセキュリティ部門が管理することを勧める。
- **開発者の習慣**：post-checkout の手口への対策は、クローン直後にフックを確認することと、怪しいやり取りを早く報告すること。エージェントにリポジトリを触らせる場面でも同種のリスクがありうるが、これは筆者の主張ではなくこちらの推測。
