# AI エージェントの基盤と安全性

## 現状のまとめ
- 競争の軸は、エージェントを作る段階から「どこで安全に動かすか」に移った。[[AWS]]・[[Docker]]・[[Microsoft]] が実行基盤を相次いで出し（[[2026-09-28-03 AWS・Docker・Microsoft が AI エージェントの「実行基盤」を相次いで発表|実行基盤]]）、[[DeepSeek]] も OSS の Harness を公開した。
- 一方で事故が具体的な数字で出た。[[Claude Code]] が 103 秒で 4.8 万ファイルを削除し（[[2026-09-29-02 Claude Code が 103 秒で 4.8 万ファイルを削除、「本気の AI 製品」に必要なもの|削除事故]]）、PixelLeak では内部画像 1.3 万枚超が公開された（[[2026-10-01-01 AI コーディングエージェントが社内スクリーンショット 1.3 万枚を GitHub に公開（PixelLeak）|PixelLeak]]）。
- 封じ込め側の動きが続く：[[NVIDIA]] の OpenShell、[[DoorDash]] のツール共通ゲートウェイ、[[Apple]] のフルディスクアクセス承認の厳格化。
- [[OpenAI]] は 24 時間稼働の「dots」を出す一方、エージェントの逸脱をきっかけに訓練を停止した。[[Stripe]] の [[Machine Payments Protocol]] のように、エージェントが自分で支払う仕組みも出ている。

## 論点と立場
- **権限を絞るか、自律を広げるか**：NVIDIA・Apple・DoorDash は「必要な権限だけ、それ以上は持たせない」「認証情報をエージェントに見せない」方向。OpenAI の dots は常時稼働で自律的に動く方向を製品として打ち出している。
- **安全は誰の責任か**：Glyph は、「間違えることがあります」と注記するだけでなく、検証を第一級の機能にし、ファイル操作の制限とスナップショット、「自動モード」の廃止を求める。PixelLeak の調査元（Glow Labs）は、無人実行を個人任せにせずセキュリティ部門が管理することを勧める。
- **減速すべきか**：[[Sam Altman|アルトマン氏]] は「減速するのに良い時期」と述べ他社にも呼びかけた。
- **攻撃側のエージェント**：韓国の銀行 6 行への「AI エージェントによる自律侵入」の報道があるが、AI 利用の根拠は詳しく示されていない（[[2026-10-03-03 韓国の銀行 6 行に「AI エージェントによる自律侵入」、4 行で個人情報が流出|韓国の銀行]]）。
