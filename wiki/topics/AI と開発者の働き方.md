# AI と開発者の働き方
**関係する問い**：[[Q1]]、[[Q3]]、[[Q7]]

## 現状のまとめ
- 「書く」をエージェントに寄せ、人は設計・契約・検証に回る実例が大きくなった。[[GitHub]] は Copilot の実行基盤の約 43 万行を、AI エージェント群と開発者 1 人で数か月かけて TypeScript から Rust に移植し（トークン費用は約 12 万ドル、旧新コードの突き合わせは複数モデルのレビュー。微妙な退行とテストを弱める懸念も、[[2026-11-11-01 GitHub が Copilot の実行基盤 43 万行を、AI エージェント群と開発者 1 人で数か月かけて Rust に移植|Rust 移植]]）、[[LinkedIn]] は週 4 万件超の PR を複数エージェントで先にレビューして最終承認は人に残し、採用率は 63.9%（[[2026-11-10-02 人のレビューを残したまま AI が先に見る：LinkedIn が週 4 万件超の PR を AI でレビュー|LinkedIn]]）。個人の SolidCraft は公開約 5 週で 150 万 DL、1 日 160〜250 件の PR を AI で回す（[[2026-11-15-02 個人開発の 3D CAD「SolidCraft」、公開から約 5 週で 150 万 DL。1 日 160〜250 件の PR を AI で回|SolidCraft]]）。数字はすべて自己申告。前週は、人のレビューを外しても hotfix・revert は増えなかったという henteko と、PR 約 10 倍の Tano が出ていた。
- 検査の自動化には、人の判断が残るという数字も並んだ。DeepMind の AlphaProof Code は Signal の暗号実装を 4 週間で形式検証し、人が確認したのは約 1%、人は「何を証明するか」を決めた（Digest 11/11、自己申告）。一方、VulnCheck は Anthropic 由来の CVE 442 件のうち悪用確認は 2 件、curl では報告の約 56% が脆弱性でなかったと示し、AWS Security Agent の PR はそのままマージ可能が 76 件中 5 件だった（Digest 11/11・11/14）。ISUCON 優勝者の記録では、手順を作り込んだ構成が素の Claude Code に負け、評価環境の選定と止め方は人の判断として残った（[[2026-11-11-03 ISUCON2026 優勝者は、人が介入しない Claude Code エージェントを 3 か月かけて作り込んだ|ISUCON]]）。
- 無人・常時稼働の運用が型として出そろってきた。Anthropic はイベント受信箱・タイマー・メモリ・権限・送信箱の 5 部品を公開（[[2026-11-15-01 Anthropic が「常時稼働エージェント」の作り方を公開。イベント受信箱・タイマー・メモリ・権限・送信箱の 5 部品|常時稼働]]）、[[Google Antigravity]] は PC を閉じても動くリモートエージェントを載せ（[[2026-11-13-05 Google Antigravity に「リモートエージェント」、PC を閉じてもクラウドで作業が続く|Antigravity]]）、個人は専用ユーザー・最小権限・毎回の本人承認で Discord から動かす（[[2026-11-13-01 Claude Code を自宅マシンで常時動かし、Discord から操作する運用（札幌 Meetup LT）|札幌 Meetup]]）。業務側ではビズリーチが業務担当者の書いたスキルを GKE 上の隔離環境で動かす基盤を作り、エンジニアは基盤と「固める判断」を担う（[[2026-11-12-03 ビズリーチが、業務担当者の書いた「スキル」を Web で動かす基盤を Codex App Server × GKE で構築|ビズリーチ]]）。Meta は複数エージェントを束ねる Conductor を買収した（Digest 11/10）。
- 使い方の知見は「指示の持ち越し」と「何に枠を使うか」に集まった。/compact を重ねると指示が最大 57% 消える検証（Digest 11/13）、役割の違う 3 つの md で前提を渡す運用（[[2026-11-13-12 CLAUDE.md・todo.md・history.md の 3 ファイルで Claude Code に前提を引き継ぐ|3 ファイル]]）、Claude Code を「コード変更」だけに絞ると出力トークンが約 1/140 になった記録（[[2026-11-13-09 Claude Code の役割を「コード変更」だけに絞ると、出力トークンが約 1 140 に|1/140]]）、公式の指南で指示書を棚卸したら 2 日で約束が 6 本増えていた非エンジニアの記録（[[2026-11-14-03 非エンジニアが Claude Fable 5.2 の公式プロンプト指南で指示書を棚卸し：2 日で逆走していた|指示書の棚卸し]]）。いずれも個人の少数回の検証。
- 雇用の話は逸話の段階にとどまる。X に「Claude Code の普及で仕事がなくなり退職した若手の応募」「税理士の退職者増加」（[[2026-11-13-03 X の投稿：「Claude Code の普及で仕事がなくなり退職した若い人からの応募が来始めた」|若手の応募]]、[[2026-11-14-05 X の投稿：「Claude Code の普及で税理士の仕事が減り、退職者が増えている」|税理士]]）、逆に Salesforce エンジニアは専門性で単価が高いという観察（[[2026-11-10-06 「大 AI 恐慌時代」でも Salesforce エンジニアは稼ぐ？ 技術の専門性が単価を支える、という X の観察|Salesforce]]）が出たが、いずれも数字はない。提供側の規約でも自由度が動いた：Claude・Codex が逆コンパイルを拒否し始めた報告（[[2026-11-12-05 AI を使ったリバースエンジニアリングが「できなくなった」報告が続出、Claude・Codex が逆コンパイルを拒否|逆コンパイル]]）。

## 論点と立場
- **全行を読むか、読まずに検査で回すか**：StrongDM は読まずに外部のシナリオ検査、HumanLayer の Dex Horthy は消灯運用に行き詰まりレビューを戻した。henteko・Tano・LinkedIn・GitHub は AI を先に置き人は承認と設計に寄せる。ただし数字は自社・自己申告で定義が揃わず、横並びでは比べられない。
- **AI の検査は信じてよいか**：検査を機械に移す側（freee、Netflix、LinkedIn、AlphaProof Code）と、成立しているかを疑う側（VulnCheck の curl、AWS Security の「マージ可能 5/76」、MaxxBench）が並ぶ。誤った指摘を人がどれだけ見抜けるかを示した数字はまだない。
- **無人で回すとき、人は何を残すか**：Anthropic の公式の型は、判断が要る操作を保留して人の返事で再開する。札幌 Meetup の運用は隔離と毎回の承認、ISUCON は評価環境と止め方の設計、ビズリーチは「固める判断」。いずれも「止め方・戻し方・承認」の設計に人が寄る。
- **残る力は何か**：判断基準・完了条件・責任（Matz の受講メモ）、説明責任と評価指標の有無で線を引く GRPI（ログラス、Digest 11/14）、EM を技術出身者に向く仕事とする議論（Digest 11/10）。Anthropic はコード試験を外した。入口で経験を積む道は細ったままという数字（FDE ノート参照）がある。
- **職種の境目は消えるか**：ビズリーチは業務担当者がスキルを書き、エンジニアは基盤を持つ分担。SolidCraft は専任チームなしの個人。一方 ISUCON は道具と手順の差が出た。「職種の消滅」か「人数の調整」かを分ける数字は今週も出ていない。
- **個人と業務の自由度**：個人は常時稼働・無料枠の組み合わせ（Muse）で進むが、提供側の規約で突然狭まる（逆コンパイル拒否）。業務側は申請・設定・確認の型（Claude Code 導入キット）を整える。
