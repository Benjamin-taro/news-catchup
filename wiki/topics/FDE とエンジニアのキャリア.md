# FDE とエンジニアのキャリア
**関係する問い**：[[Q1]]、[[Q3]]、[[Q5]]

## 現状のまとめ
- FDE が「ベンダー側の職種」として銀行の AI 構築に入った例が出た。米 [[Northern Trust]] は [[Microsoft]] の Forward Deployed Engineering チームと顧客オンボーディングのエージェントを作り、データ準備時間を 83% 減、期間を 2 週間半から 3 日にしたとされる（アナリストが結果を確認・承認する形。FDE の作業範囲と費用の内訳は記事になく、数字は発表側の自己申告。[[2026-11-12-01 Northern Trust が Microsoft の FDE と顧客オンボーディングのエージェントを構築：データ準備 83% 減、2 週|Northern Trust]]）。10/29 の Microsoft の FDE 論（職種というより能力、単位は多職種のポッド）と、Atlassian の「契約終了後も顧客が依存し続けるならコンサル」という線引きに、実例が 1 つ加わった形。
- FDE を「新しい職種」でなく再登場した役割として見る材料が出た。Ian Miell は 1940 年代から現在までの職種名 104 個を 7 つの系統に分け、Palantir の FDE（2010 年ごろ〜）は 1960 年代の IBM のシステムエンジニア（営業支援の技術職）に似ると指摘した。「プロンプトエンジニア」は 2023 年がピークで AI エンジニアに吸収されつつあり、最も新しい枝は 2025 年ごろの「AI Agent / Context Engineer」。年代は筆者の推定で出典付きではない（[[2026-11-15-03 ソフトウェアの職種名 104 個の「家系図」。名前は何度も付け替えられ、FDE は 1960 年代の IBM のシステムエンジニアに似る|家系図]]）。
- 役割の議論は「技術出身者が組織・構造の問題を解く」側にも広がった。mtx2s 氏は EM を、組織をシステムとして捉え構造的な問題を解く仕事で技術出身者に向くとし、密結合の解消で調整が不要になった例を挙げた（[[2026-11-10-08 「EM は魅力のない役割ではない」：組織の課題解決は、エンジニアリングの延長にある|EM]]、経験談）。ログラスの GRPI は、説明責任は人に残り変わるのは「確かめ方」とし、評価指標が明確なほど AI に大きく任せられるとした（[[2026-11-14-02 「人間＋AI のチーム」を GRPI で再設計する（ログラス・AI 駆動経営勉強会）|GRPI]]、人間と AI の関係性は「まだ答えのない課題」）。
- 雇用の数字は出ず、逸話が続いた。X に「Claude Code の普及で仕事がなくなり退職した若手の応募」「税理士の退職者増加」（[[2026-11-13-03 X の投稿：「Claude Code の普及で仕事がなくなり退職した若い人からの応募が来始めた|若手の応募]]、[[2026-11-14-05 X の投稿：「Claude Code の普及で税理士の仕事が減り、退職者が増えている|税理士]]）、逆に Salesforce エンジニアは大企業向けで単価が高くクラウドとの掛け算ができるという観察（[[2026-11-10-06 「大 AI 恐慌時代」でも Salesforce エンジニアは稼ぐ？ 技術の専門性が単価を支える、という X の観察|Salesforce]]）。どれも投稿者・件数・年収の数字がなく、「職種の消滅」か「人数の調整」かは判断できない。
- 前週までの流れ：Anthropic の社内データで技術職の新規採用に占める初級職が 27% → 9%、Will Larson の「マネージャーが技術判断に戻る」、Matz の受講メモ（責任・問い・合否の基準）、FDE の報酬が最大 150 万ドルという根拠なしの報道、インドの FDE 求人は前年比約 19 倍だが 6 月がピーク、Barclays・Amex の人員削減（AI の内訳なし）。

## 論点と立場
- **どこに価値が残るか**：判断と責任（ファクトリー論、Matz）、技術判断に戻るマネージャー（Larson）、構造の問題を解く EM（mtx2s）、説明責任と評価指標の線引き（GRPI）と、「上流・判断」に寄る見方が並ぶ。入口の初級職が減る数字がある一方、残る側に至る道筋を示した記事はない。
- **FDE は職種か、能力か、再登場した役割か**：Microsoft は能力・ポッドと見ながら「エンジニアであること」を条件に置く。Atlassian は終わることを前提に設計しなければコンサルだと線を引く。Miell は 1960 年代の IBM の SE に似るとする。Northern Trust はベンダー側の FDE との共同構築。どれも人数や定着を示す数字はなく、一次データ（求人の増減、専任組織・資格・キャリアパス）は出ていない。
- **技術の専門性は価値を保つか**：Salesforce エンジニアの単価の観察は「専門知識は重宝されなくなる」に反する材料だが逸話。「Claude Code で職を失った」という投稿は逆向きで、こちらも数字なし。両方とも逸話にとどまる。
- **初級職の減少は AI のせいか**：Anthropic の数字は社内データで、ファクトリー論の筆者も因果までは確定できないとする。Barclays と Amex も AI の寄与は内訳なし。
- **FDE の報酬は続くか**：Tekedia は最大 150 万ドルを伝えつつ自ら一般的な給与ではないと断る。需要が落ち着けば減りうる。
- **置き換わる側をどうするか**：みずほは希望者を開発側に回す設計。待遇や評価は記事にない。
