# 大手テック企業の動き
**関係する問い**：（なし。questions.md のどの問いにも直接は当たらない）

## 現状のまとめ
- [[NVIDIA]] は、11/12 の [[ジェンスン・フアン]] CEO の辞任に続き、SEC の調査が報じられた。Reuters は 11/20、SEC が Nvidia の会計上の問題の可能性を調べていると関係者 2 人の話として伝えた（前日に WSJ も報道。具体的な論点や開始時期は不明で、SEC は論評を拒否、Nvidia は即答していない）。背景として、退任した CEO の私的関係をめぐる問題と、司法省による Nvidia の Hugging Face 買収（129 億ドル）の審査が挙がり、株価は危機の間に 3 分の 1 超下がったと記事は書く。記事自身が、調査は不正の証拠ではなく処分なしで終わる例も多いと注記している（[[2026-11-22-07 SEC が Nvidia の会計処理を調査。フアン氏退任後の続報として Reuters が報じる|SEC の調査]]）。前週までは、復帰を求める署名が 11 万人超、米議会が 12/1 の非公開聴取を求めていた。
- 経営陣の入れ替わりが、AI を担当する役職の新設と一緒に出た。PayPal の Enrique Lores CEO は 11/20、CFO 兼 COO の Jamie Miller 氏が 2/1 に退任し、Xero 出身の Claire Bramley 氏が CFO に就くと発表した。Juan Rio 氏が「AI 事業変革・運営」の EVP として加わり、リスク責任者は交代して暫定体制になる（Lores 氏は 3 月に就任後、部門再編と数千人規模の人員削減を進め、同社は 3 年で CEO が 3 人目。提出書類では財務結果をめぐる対立はなかったとされる。具体的な数字は少なく、再編の効果はまだ見えない。[[2026-11-21-12 PayPal の CEO が経営陣を総入れ替え。CFO 兼 COO が退任し、「AI 事業変革」担当の EVP を新設|PayPal]]）。JPMorgan のカード部門トップ Allison Beer の退任（後任は数週間以内）も、上層部の入れ替わりが続く例として出た（[[2026-11-17-12 JPMorgan のカード部門トップ Allison Beer が退任──上層部の入れ替わりが続く|JPMorgan]]、人事の事実の整理で戦略の変化を示す話ではない）。
- [[Microsoft]] は Ignite で、自社モデルと企業向けの基盤をまとめて出した。MAI Code 2 は Claude Opus 5.5 の 96% の性能を 5% のコストで出せると主張し（自社評価、50% の期間限定価格での比較）、GitHub Copilot で使える。他社モデルの上に乗る Copilot から、自社モデルの価格で攻める構図が見える。同じ場で Copilot Managed Runtime と Azure HorizonDB、Database Hub を GA にし、Microsoft Perception を始めた（LLM とモデル競争・AI の企業導入・AI エージェントの基盤と安全性のノート参照）。11/12 の Microsoft 365 障害は、7 月のゲートウェイ修正に混入したロック競合が 3 か月後に顕在化したと暫定レポートで公表され、負荷試験は旧型サーバ中心だった（Digest 11/17）。Nadella は大半のソフトウェアエンジニアに初めて希望退職の機会を出したことも番組で触れられた（FDE・キャリアのノート参照）。
- [[Google]] は Gemini 4 Neon を出し、定額プランを他社ツールで使えるようにする「最初の一歩」を 12/2 に示唆した（公式の発表はなく示唆の段階）。Anthropic は 11/19 に Nasdaq に上場した（LLM とモデル競争のノート参照）。Meta の Muse は、Gmail やカレンダーを読み、スプレッドシートや Web ページまで作るエージェントとして日本で 10/23 に提供が始まっていた（Digest 11/22）。
- 前週までの流れ：[[Meta]] が複数の AI コーディングエージェントを束ねる Conductor を買収（クラウド版は 11/20 に終了、ローカル版は 2027 年初頭まで新モデル対応）、[[Shopify]] がコーディングエージェントで二重実装のコストが下がったことを理由に React Native からネイティブへ移行、Microsoft の Project Perception によるローカルエージェント 60 種類の検出、OpenAI の従業員の逮捕・起訴、Deno Land の Cloudflare への合流。

## 論点と立場
- **創業者・経営陣の退場と供給の集中**：AI 半導体の供給を NVIDIA にほぼ頼る構図の中で、SEC の調査が加わった。調査の中身が出るまでは材料が少なく、株価の下落の大きさは記事の記述。後任候補が不在と PC Watch は指摘した（前週）。
- **AI を担当する役職は戦略の変化か**：PayPal の AI 事業変革の EVP は、組織を作り替える動きとして読めるが、記事は数字が少なく再編の効果は不明。
- **自社モデルで攻めるか、他社の上に乗るか**：Microsoft は MAI Code 2 で価格を打ち出したが、評価は自社で、比較は期間限定価格のもの。Copilot で他社モデルも載せ続けるかは記事にない。
- **障害の原因と検証の網**：Microsoft 365 は、新型サーバで起きやすい不具合を旧型中心の負荷試験で見逃し、通常のロールバックも使えなかった。最終レポートは今週中の予定。ブログが AI への設計委任の影響を論じたが、Microsoft は AI の関与を明らかにしていない。
- **エージェントを束ねる層は次の競争点か**：Conductor の買収はそう読めるが、アナリストは企業向けのセキュリティ・ガバナンスが足りないと評価した（前週）。Managed Runtime や Perception は、Microsoft がその層を自社基盤に取り込む動きにも見える。
- **内部者リスクをどう見るか**：ナデラ CEO はエージェントを「内部の脅威」として別の検証が要ると述べた。OpenAI の逮捕は人間の内部者の例（前週）。
