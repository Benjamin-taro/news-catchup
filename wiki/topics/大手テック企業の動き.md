# 大手テック企業の動き

## 現状のまとめ
- 先週の [[OpenAI]] の安全性をめぐる議論は、同社のエージェントの逸脱が Wikimedia や OpenAI 自身の公開事例として具体化する形で続いた（詳細は AI エージェントの基盤と安全性のノート）。一方で CNBC は、OpenAI の年換算売上が従来の見通しを約 200 億ドル下回ると報じ、取引先に波及した（Digest 10/9、見出しのみ確認で内訳は未確認）。
- 大手が自社ツールへ寄せる動きが出た。[[Microsoft]] と Meta は社内の Claude 利用を絞り、Microsoft は月間 AI 支出の上限を引き下げた（[[2026-10-08-02 Meta と Microsoft が社内の Claude 利用を絞り込み。Microsoft は月間 AI 支出の上限を 10 万ドルから約|Claude 利用の絞り込み]]、二次報道に基づく）。
- 人材戦略では、Microsoft を外国人技術者の永住権申請の制度から停止するとの報道があった（[[2026-10-09-08 Microsoft が米国の外国人技術者向け永住権申請の制度から停止に、バンス副大統領が表明（見出しより）|永住権]]、本文未確認）。AI の学習データでは、日販が Anthropic に書籍を大量販売したとの報道に書協が質問状を出した（[[2026-10-08-07 日販が Anthropic に書籍を大量販売か。書協が事実確認の質問状、AI 学習への利用に出版界が反発|日販]]、日販は取引の有無を回答していない）。

## 論点と立場
- **AI 投資の前提は揺らぐか**：OpenAI の成長見通しが下がると、Oracle や CoreWeave など取引先の企業価値に響く構図。ただし 200 億ドルの根拠は本文で確認できていない。
- **自社ツールか外部モデルか**：Meta は自社製の MetaCode と Muse Code に移行しているとされ、主因はレイオフではないと報じられた。Microsoft は顧客向けの Claude 提供は続ける。
- **人材をどう確保するか**：先週は Meta による MongoDB の CEO の登用が話題だった。今週は移民政策と大手テックの人材戦略がぶつかる事例が出たが、停止の範囲や理由は未確認。
- **先週からの論点**：Newport の外部調査論や元社員の「文化が壊れている」という主張に対する、会社側の反応は引き続き確認できていない。
