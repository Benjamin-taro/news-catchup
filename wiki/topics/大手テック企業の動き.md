## 現状のまとめ
- 基盤の選び方が AI で動いた例が出た。[[Shopify]] は、モバイルアプリを React Native からネイティブ（Swift/Kotlin）へ作り直した。2020 年は機能の二重実装を避けるために採用したが、コーディングエージェントが片方からもう片方へ移植できると確認できて不利が薄れたという。Shop アプリは 12 週間で公開し、起動時間は iOS が約 3,200ms から約 2,400ms、Android が約 4,400ms から約 2,200ms になった（[[2026-10-21-05 Shopify が React Native をやめ、Swift Kotlin のネイティブに移行。コーディングエージェントが「二重実装のコ|Shopify]]、Shopify の自己申告を ByteByteGo が整理）。
- [[Microsoft]] はエージェントの統制へ踏み込んだ。社内の自律エージェントを統制する Project Perception を拡張し、ローカルで動くエージェント 60 種類（Claude Code、Codex、GitHub Copilot を含む）を検出する（Digest 10/21、招待制のプレビュー）。業務側では、Copilot しか使えない人が Claude を使える企業との差を気にするという X の声もあった（[[2026-10-24-12 「仕事ではCopilotしか使えない。Claude が使える企業と差がつくのでは」。業務で使える AI の制限が品質差に見えるという X の|Copilot]]、1 件の投稿）。
- [[Anthropic]] は社内の雇用データ、攻撃対象領域の削減、形式的検証と、自社の研究を相次いで公開した（各トピックのノート参照）。数字はいずれも自社データで、第三者の検証はない。
- 前週の出来事：[[OpenAI]] の従業員が役員会議室に録音装置を仕掛けた疑いで逮捕・起訴された件（OpenAI は重み・ソースコード・顧客データへの不正アクセスの形跡は確認されていないと説明）。Anthropic の Scion をめぐる設計の帰属の指摘、Deno Land の Cloudflare への合流。

## 論点と立場
- **AI でコストが安いのはどこか**：Shopify は、二重実装のコストが下がったことでクロスプラットフォーム基盤の前提が崩れたと説明する。数字は自己申告で、300 画面超の Shopify アプリ本体の移行はこれから。
- **内部者リスクをどう見るか**：ナデラ CEO は、モデルを内部者リスクと同じに扱うよう提言した。OpenAI の逮捕は人間の内部者の例で、動機や被害の中身は不明。
- **設計の帰属**：Mononoke の設計者は、LLM は既存の設計に寄りやすいとして、先行事例の明記を求めた。Anthropic 側の反論は記事にない。
- **独立系ランタイムの行方**：Deno のコードはオープンソースなので他の開発者が継続する余地は残る。
