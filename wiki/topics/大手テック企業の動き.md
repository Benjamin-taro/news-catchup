# 大手テック企業の動き

## 現状のまとめ
- [[OpenAI]] の内部者の事件が出た。従業員（35 歳）が役員会議室に録音装置を仕掛けた疑いで逮捕・起訴され、Agents SDK チームの社員だったとも伝えられた（[[2026-10-14-09 OpenAI の従業員が、役員会議室に録音装置を仕掛けた疑いで逮捕・起訴|逮捕・起訴]]、[[2026-10-16-10 OpenAI の Agents SDK チームのエンジニアが、社内の会議室に録音機器を仕掛けた疑いで逮捕。FBI・司法省が関与|Agents SDK チーム]]）。OpenAI は、モデルの重み、ソースコード、顧客データへの不正アクセスの形跡は確認されていないと説明する（会社側の説明）。拘留審理は 10/19。
- 設計の出自と帰属が論点になった。[[Anthropic]] が公開した Scion について、Meta で Mononoke を設計した著者が「盗用に近い」と指摘した（Digest 10/15、設計者本人の見解で Anthropic 側の反論は記事にない）。
- 独立系の開発基盤が大手に吸収される動きもあった。Deno Land が Cloudflare に合流し、Deno 本体は 1 年後、Deno Deploy は 6 か月後に開発を終了する（Digest 10/13）。[[Microsoft]] は、ナデラ CEO の提言と MXC の正式版、Copilot for Legal と、エージェントの統制や法務の基盤へ踏み込んだ（各トピックのノート参照）。
- モデルでは、[[Meta]] が Muse Spark Open、Google が Gemini 4 Argon、DeepSeek が V4.1 Flash を出した（詳細は LLM とモデル競争のノート）。

## 論点と立場
- **内部者リスクをどう見るか**：ナデラ CEO は、モデルを内部者リスクと同じに扱うよう提言した。今回の逮捕は人間の内部者の例で、動機や被害の中身は不明。企業向けに AI を提供する会社の内部統制は、導入側の確認項目にもなりうる。
- **設計の帰属**：Mononoke の設計者は、LLM は既存の設計に寄りやすいとして、先行事例の明記を求めた。2 つのモデルに先行事例を尋ねると、どちらも Mononoke を挙げたという。
- **独立系ランタイムの行方**：Deno のコードはオープンソースなので他の開発者が継続する余地は残る。Dahl 氏は Workers のプログラミングモデルをサーバアプリのメインストリームにしたいと述べた。
- **先週からの論点**：OpenAI の売上見通し、Newport の外部調査論、元社員の「文化が壊れている」という主張に対する会社側の反応は、今週も確認できていない。
