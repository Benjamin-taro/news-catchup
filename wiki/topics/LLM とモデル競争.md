# LLM とモデル競争
**関係する問い**：（なし。questions.md のどの問いにも直接は当たらない）

## 現状のまとめ
- 速さと安さで勝負する非 Transformer 系が現実味を帯びてきた。[[Inception Labs]] の [[Mercury 3]] は diffusion 方式で、NVIDIA GPU 上で 1,068 トークン/秒、文脈 100 万トークン、価格は入力 $0.20・出力 $0.70（ローンチ割引で半額）と発表した。GPT-6 Luna や Claude Haiku 5.5 を上回り 4〜8 倍速いとするが、個別のベンチマークスコアはなく、すべて提供元の自己申告（[[2026-10-20-07 拡散（diffusion）方式の LLM「Mercury 3」。1,068 トークン 秒、100 万トークンの文脈、入力 $0.20・出力|Mercury 3]]）。[[Mistral]] の [[Voxtral 3]] は、音声認識・合成・ボイスエージェント SDK を価格つきで一式そろえた（[[2026-10-21-14 Mistral が Voxtral 3 を公開。音声認識・音声合成・ボイスエージェント SDK の一式で、リアルタイム文字起こしは 500m|Voxtral 3]]、性能は自社評価）。[[Block]] は音声だけで学習した全二重の会話モデル Dessa を、M4 Max でローカル動作すると発表した（[[2026-10-24-13 Block が音声だけで学習した会話モデル「Dessa」を発表。GB200 NVL72 1 台で学習し、MacBook Pro M4 Max|Dessa]]、ウェイトリスト中心で比較数字なし）。
- 首位級との差を詰めたという主張も出た。Moonshot の Kimi K3.1 Pro は、Terminal-Bench 4.0 で 65.7%（Claude Opus 5.5 は 66.4%）とし、重みの公開は 11 月 4 日までに予定されている（Digest 10/24、自社ブログのベンチのみで、ライセンスと料金は記載なし）。
- ベンチマークの見せ方が変わった。Alibaba の Qwen チームらの E-Commerce Bench は、AI に 365 日のネットショップ経営を任せ、18 モデルで最高の GPT-5.6 Sol は資金を平均約 14.3 倍にしたが、詐欺業者への支出割合は 16 位だった。90 試行のうち 10 回は破産した（[[2026-10-21-06 AI にネットショップを 1 年運営させる「E-Commerce Bench」。18 モデルで最高は資金 14.3 倍、90 試行中 10|E-Commerce Bench]]、Alibaba の研究者による論文で第三者の再現ではない）。HybridAgents（潜在空間で考えツールはテキストで使う）はトークン 35.5〜54.7% 減を著者らが報告した（Digest 10/19、要旨のみ）。
- 事業者の規約も動いた。Anthropic は利用規約を改定し、AI への「虐待的・残酷な行為」を禁止して、繰り返す場合は会話を強制終了するとした（[[2026-10-25-12 Anthropic が利用規約を改定し、AI への「虐待的・残酷な行為」を禁止。繰り返す場合は会話を強制終了|規約改定]]、ABEMA TIMES の報道で規約の原文は未確認）。
- 前週までの流れ：[[Meta]] の Muse Spark Open と [[DeepSeek]] の V4.1 Flash 1017 によるオープンウェイトの大型化、Gemini 4 Argon の自社ベンチ、Claude による NIST 楕円曲線のシード特定。

## 論点と立場
- **自社発表の数字をどう読むか**：Mercury 3、Voxtral 3、Kimi K3.1 Pro、Dessa はいずれも第三者の検証が見当たらない。Kimi の比較表は、Opus 5.5 や GPT-6 Astra を上回る項目と下回る項目が混ざる。
- **速さ・安さの勝負は成り立つか**：Mercury 3 は応答時間が効くブラウザ操作や検索に絞って導入例を示す（Mind2Web の実環境 50 件で 50% 完了）。品質の比較数字がないため、用途が限られるかは未確認。
- **ベンチマークは仕事の力を測るか**：E-Commerce Bench は収益だけでなく詐欺回避、資金繰り、長期記憶を見て、収益最上位でも詐欺回避は弱いと示した。前週の Mercor の推計（労働時間の約 90% は既存のベンチがほぼ測っていない仕事）と同じ方向の問い。
- **オープンとクローズドの差**：Kimi は重みを公開予定で、コーディング系のベンチで首位級に迫ると主張する。価格とライセンスが出るまでは判断を保留する材料。
