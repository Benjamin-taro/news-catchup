# LLM とモデル競争
**関係する問い**：（なし。questions.md のどの問いにも直接は当たらない）

## 現状のまとめ
- コーディング向けの新モデルが各社から出て、公表値に第三者の指数が付き始めた。Microsoft は MAI Code 2 を発表し、4 つのベンチの平均で Claude Opus 5.5 の 96% の性能を 5% のコストで出せると主張した（50% の期間限定価格での比較で、独立した検証は未確認。Digest 11/18）。[[Google]] の Gemini 4 Neon は Artificial Analysis の Coding Agent Index（58.6）で 1 位、Intelligence Index（61）で 3 位、入力 $3・出力 $15、キャッシュ入力は 95% 引き（数字は Google の公表値。[[2026-11-19-04 Google「Gemini 4 Neon」――コーディング指数 1 位を主張、入力 3 ドル／出力 15 ドル|Gemini 4 Neon]]）。個人運営の指数 Mei では 4 Neon が 68.1 で 20 モデル中 1 位、[[Claude Fable 5.2]] が 66.3 で 2 位だがコストは 4 Neon の約 3.7 倍（公開日の記載も誤差範囲もなく、小さな差には意味がない可能性。[[2026-11-20-08 新指標 Mei で Google の「4 Neon」が 1 位。Fable 5.2 は 2 位だがコストは約 3.7 倍|Mei]]）。
- 小さく・手元で動く方向と、モデルが自分を直す研究が出た。Thinking Machines の Inkling 2 Mini は 26.4B の MoE（活性 3.4〜5.4B）で約 20GB、SWE-bench Verified 79.2% と自社公表した（弱い項目も明記、第三者の再現は未確認。Digest 11/21）。それを 5.4GB に圧縮した版は、M5 Max で約 75 トークン/秒だが HumanEval が 92.7% → 71.3% に落ちた（公開者の自己測定。Digest 11/22）。1.8M パラメータで Sudoku-Extreme 99.4% の Energy-Based Reasoners（プロジェクトページのみ。Digest 11/19）、27B モデルが勾配なしで自分の重みを書き換え、未見の問題で 6.6 ポイント改善した arXiv の投稿（査読前、自己申告。[[2026-11-21-14 「言語モデルは自分の重みを書き換えられる」。27B モデルが勾配なしで自分を直し、未見の問題で 6.6 ポイント改善（arXiv）|self-rewriting]]）もある。
- 数学の証明が、AI と Lean で一気に動いた。Alpöge 氏が一般化リーマン予想の「Lean だけの証明」を内部 AI モデルで作ったと 11/20 に公開し、Tao 氏は同日の Euler・Navier-Stokes の有限時間爆発の主張とあわせて紹介しつつ「まだ初期」と書いた（モデル名は確認できていない。[[2026-11-21-01 一般化リーマン予想（GRH）の「Lean だけの証明」を AI で作ったと Alpöge 氏が公開。Tao 氏は「まだ初期」|GRH]]）。11/22 には Lean と Mathlib のコミュニティが、約 1,700 万行の証明を複数のチェッカーで検証し、定理の述べ方が Mathlib の `RiemannHypothesis` の定義と一致することも確認したと声明を出した。保証するのは形式コードの正しさで、数学的なアイデアの理解や査読の代わりではなく、AI の利用には触れていない（[[2026-11-22-01 リーマン予想の Lean 証明、Lean・Mathlib コミュニティが「公式に検証済み」と声明（11 21 の続報）|公式声明]]）。
- 使う側の判断材料。Pragmatic Engineer の推論エンジニアリングは、フロンティア API からオープンモデルへの移行でトークン単価が Uber 約 50%、Pinterest 90%、AT&T 56% 下がったとし（自己申告）、公開ベンチでなく自社トラフィックで、トークン単価でなくタスク単価で比べることを勧める（[[2026-11-18-08 Pragmatic Engineer「推論エンジニアリング」──フロンティア API からオープンモデルへ：Uber 50%、Pintere|推論エンジニアリング]]）。推論時に考えさせすぎて精度が落ちる 2 つの失敗パターンの解説（[[2026-11-18-11 推論させすぎると LLM はなぜ間違えるのか──「2+3」に 13 通りの解を出す無駄と、誤った前提|推論のしすぎ]]）、Google が Gemini の定額プランを他社ツールで使えるようにする兆し（12/2 に「最初の一歩」、公式発表はなく示唆の段階。[[2026-11-21-09 Google が Gemini の定額プランを他社ツールで使えるようにする兆し。12 2 に「最初の一歩」|定額プラン]]）もあった。前週までは、Fable 5.2 の実測（差は単価の差とキャッシュ書込がほぼ全て）、Gemini 4 Hydrogen と Decisions API が出ていた。
- 業界の外側のリスクは、資本市場に移った。Anthropic は 11/19 に Nasdaq へ上場し、公開価格 83 ドル・評価額約 1.5 兆ドル、調達額は約 794 億ドルだった（1〜9 月の売上 332 億ドル、純損失 1,040 億ドルは主に転換社債の会計処理とされる。同日の日経平均は AI・半導体株への売りで午前に 2,669 円安。Digest 11/20）。Nvidia は創業者の退場に続き SEC の調査が報じられた（大手テック企業の動きのノート参照）。提供側の規約で使い方が狭まる例（逆コンパイル拒否）が前週に出ていた。

## 論点と立場
- **自社発表の数字をどう読むか**：MAI Code 2（期間限定価格での比較）、Gemini 4 Neon、Inkling 2 Mini はいずれも提供元の数字。第三者の指数（Artificial Analysis、Mei）が付いたものでも、Mei は個人運営で誤差が示されない。Fable 5.2 は前週の実測で「安い」の中身（単価とキャッシュ書込）と「速い」が確認できなかった。
- **首位はコストと別か**：Mei では性能の首位（4 Neon）とトークン効率の首位（6.2 Astra は 0.31 倍）が別のモデルで、Fable 5.2 は 2 位だが約 3.7 倍のコスト。1 つの指数で選ぶより、自社のタスクで測る（Pragmatic Engineer）という立場と重なる。
- **形式検証が済むと何が人に残るか**：Lean のコミュニティは形式コードの正しさを機械側で確かめたが、証明の鍵になった新しいアイデアを数学者が説明する作業はこれからだと断る。Tao 氏は消化に時間がかかるとする。検証が機械に寄っても、読み解く仕事は残るという見方（Q1 の材料）。
- **端末内で動く小型モデルの質**：Inkling 2 Mini は手元の PC で動くが、圧縮すると HumanEval が約 20 ポイント落ちた。ベンチは自前で貪欲デコード、速度は M5 Max 1 台の値。
- **大型と安価な高速モデルの使い分け**：Gemini 4 の Carbon・Neon・Hydrogen、MAI Code 2 と Flash、Fable 5.2 と Opus 5.5 のように階層を持つ売り方が揃った。コスト比較にはキャッシュの当たり外れも効く。
- **上場とモデル会社の見通し**：Anthropic の上場は、フロンティアラボが公開市場で値付けされる初の例として見られている。純損失の主因は会計処理とされ、AI 投資の空気との関係は記事側の見立て。
