# LLM とモデル競争

## 現状のまとめ
- [[Anthropic]] が 11/9 に [[Claude Fable 5.2]]（全ユーザー向け）と Mythos 5.2（審査を通った組織向け）を公開した。Fable 5.2 は FrontierSWE v2 で 69.9%（Fable 5.1 は 56.3%、Opus 5.5 は 62.3%）、業務ワークフローを測る AutomationBench で 51.4%（5.1 は 31.4%）、価格は入力 100 万トークンあたり $8・出力 $40。数字は Anthropic の公表値（[[2026-11-10-01 Anthropic が Claude Fable 5.2 と Mythos 5.2 を発表。コーディングと業務ワークフローの指標が大きく伸び|Fable 5.2 の発表]]）。
- 第三者・個人の実測は、公表値をそのまま信じない読み方を促した。33 回の実測では 5.1→5.2 の表示額の差はほぼ単価の差（8 割）で、キャッシュ書込が起きた回は約 30 倍高く、「出力 30% 速い」は確認できなかった（[[2026-11-10-04 Fable 5.2 は「2 割安い」のか：33 回の実測では、差は単価の差とキャッシュ書込がほぼ全て|実測]]）。ローポリ 3D 素材では Fable が全題材で良く費用は約 1.7 倍（[[2026-11-12-11 Fable 5.2 と Opus 5.5 にローポリ 3D 素材を組ませて比較：Fable が全題材で良く、費用は約 1.7 倍|3D 比較]]）、物理モデリング音源ではピアノとギターが強く Opus 5.5 は弱かった（[[2026-11-14-04 Fable 5.2 に物理モデリング音源の実装と作曲をさせると、ピアノとギターが特に強い|音源]]）。いずれも 1 人の目視か少数回で、「1 タスクの費用が約半分」は 1 件の評価での比較（[[2026-11-15-04 Claude Code 週間まとめ（11 8〜11 14）：Fable 5.2 は入力 $8・出力 $40、sandbox 内の Bash|週間まとめ]]）。
- [[Google]] は 11/11〜11/12 に「判定」だけを返す Gemini Decisions API（最大 1,000 問・150〜250 ms・入力 100 万トークン 0.10 ドル）と、コーディング・エージェント向けの高速モデル Gemini 4 Hydrogen（入力 $1.50・出力 $7.50、Artificial Analysis の指数は標準で 51）を出した（[[2026-11-12-07 Google の Gemini Decisions API：1 回の入力に最大 1,000 問を 150〜250 ms で判定、入力 100|Decisions API]]、[[2026-11-13-08 Google が Gemini 4 Hydrogen を発表、1M トークンで入力 $1.50 出力 $7.50|Gemini 4 Hydrogen]]）。大型モデルと安価な高速モデルを使い分ける売り方が各社で揃い、数字はどちらも Google の自己申告。
- 力関係の外側のリスクが 2 つ出た。[[NVIDIA]] の [[ジェンスン・フアン]] CEO が 11/12 に辞任し CFO が暫定 CEO に、復帰を求める署名は 11 万人超、米議会が 12/1 の聴取を求めている（[[2026-11-13-02 NVIDIA のフアン CEO が辞任、CFO が暫定 CEO に|フアン氏の辞任]]）。提供側の規約でも、Claude・Codex が逆コンパイルを拒否し始めた報告があり、404 Media は作業がオープンウェイトやローカルのモデルへ移ると見る（[[2026-11-12-05 AI を使ったリバースエンジニアリングが「できなくなった」報告が続出、Claude・Codex が逆コンパイルを拒否|逆コンパイル]]）。
- 設計の判断材料としては、長い文脈を丸ごと渡す「全文プロンプト」と RAG の使い分けの整理（[[2026-11-14-09 『検索システム』『推薦システム』二部作：LLM 時代の「全文プロンプト」と RAG の使い分け|検索システム]]、著書の紹介で実測なし）。前週までの流れ：Mercury 3（diffusion 方式で 1,068 トークン/秒）、Kimi K3.1 Pro（Terminal-Bench 4.0 で Opus 5.5 に迫ると主張）、E-Commerce Bench。

## 論点と立場
- **自社発表の数字をどう読むか**：Fable 5.2、Gemini 4 Hydrogen、Decisions API、Mercury 3、Kimi はいずれも提供元の数字が中心。Fable 5.2 は実測で「安い」の中身（単価とキャッシュ書込）と「速い」が確認できず、公表値と使い方で測った値は別。
- **差はベンチマークか、仕事か**：Fable は評価した項目でほぼ Opus 5.5 を上回るとされるが、創作系の比較は目視の 1 人評価で、差の一部は条件（新しいセッション）による。業務ワークフロー（AutomationBench）の伸びが大きい点は、任せる範囲が広がる方向。
- **大型と安価な高速モデルの使い分け**：Gemini 4 Hydrogen と Antigravity の Orchestrator、Decisions API の振り分けは、1 つの最強モデルでなく役割分担で回す前提。コスト比較にはキャッシュの当たり外れも効く。
- **供給の集中リスク**：AI 半導体を NVIDIA にほぼ頼る構図で創業者が突然退場した。後任が決まるまで調達計画に不確実性が残るというのは記事側の見立て。
- **提供側の規約で使い方が狭まる**：逆コンパイルの拒否は、個人の自由度がポリシーに左右される例。家電メーカーの要請かは不明で、404 Media の見立て（ローカルへの移行）は未検証。
