# LLM とモデル競争

## 現状のまとめ
- オープンウェイトの新顔が続いた。[[Reflection AI]] は初のオープンウェイトモデル [[Beam]]（総 5010 億パラメータ、Apache 2.0 で公開予定）を発表した（[[2026-10-06-09 Reflection が初のオープンウェイトモデル「Beam」。総 5010 億パラメータ、Apache 2.0 で公開予定|Beam]]）。Mistral も Large 4 を発表した（Digest 10/7、重みは月末公開予定）。数字はいずれも自社発表。
- 競争の軸は、自社モデルの囲い込みから複数社のモデルを束ねる基盤へ動いている。[[Google]] の Gemini Agent は [[Claude]] の Opus 5.5 と Sonnet 5.5、Gemini 4 Argon を選べる（[[2026-10-10-07 Google が「Gemini Agent」を発表、Claude Opus 5.5 Sonnet 5.5 を搭載。他社モデルも順次追加|Gemini Agent]]）。[[Anthropic]] は Haiku 5.5 を安価に出し、軽い作業を任せる構成を前提にした価格にした（Digest 10/8）。
- 研究面では、OpenAI が数学での AI の進展を共有した（[[2026-10-07-10 OpenAI が「数学における AI の進展」を共有（HN 🔥）。数学の未解決問題への成果をめぐる流れの続き|数学]]、本文未確認）。Anthropic が宗教学者らと Claude の道徳観を協議していたとの NYT 報道も出た（[[2026-10-05-10 Anthropic が宗教学者を招き、Claude の道徳観と「意識」の可能性を協議していた（NYT 報道）|NYT]]）。

## 論点と立場
- **発表の数字をどう読むか**：Beam や Large 4 のベンチマークは自社発表で、第三者の検証は未確認。Beam の重みの公開は「予定」で、今は早期アクセスの登録段階。
- **どのモデルをどの仕事に使うか**：Haiku 5.5 の公表では複雑なコーディングは Sonnet 5.5 や Opus 5.5 向けとされ、役割分担が価格に織り込まれている。先週の McKinsey の見立てにもあるオープンウェイトへの振り分けと並ぶ見方。
- **価値観の設計を誰が担うか**：Anthropic は外部の思想家を招いたとされるが、会合の中身の多くは非公開のまま。共同創業者は意識の有無について「本当に確信がない」と述べた。
- **先週からの論点**：独立評価（Livenerf）と自社発表の数字の差、AI が AI を作る研究（[[ELYZA]]）は続いている。
